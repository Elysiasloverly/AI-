# 远程怪固定点与就近刷新

更新：2026-11-09。

## 为什么改为就近激活

地图四周的 12 个点现在作为候选入口，不再每波轮流使用整张地图的点。地图很大时，旧做法会把一波远程怪拉得过散，固定不动的怪尤其容易留在远处，需要玩家跑图收尾。

当前规则：

1. 按当前刷怪参考玩家的距离排序，只轮换附近最近的 3 个可用点。
2. 固定点的激活距离上限为正常目标出生半径的 1.25 倍，至少保留“玩家最小安全距离 + 300 cm”的空间。正常目标半径与安全距离继续读取游戏平衡配置。
3. 附近没有点、点位太远或暂时被占住时，在玩家附近的合法地面生成；这条回退路径不会再到地图另一端选点。
4. 不动的炮台类怪物使用更近的出生圈，同时保持与玩家的最小安全距离和原有不移动行为。
5. 所属区域的点若被全部手动禁用，仍尊重禁用设置，不使用回退来绕过该配置。

所有候选位置仍通过不规则刷怪轮廓、禁刷区、地面高度、可站立地面、实际胶囊空间、敌人间距以及所有存活玩家的安全距离检查。失败不消耗本波名额。由服务器决定实际位置。

## 编辑关卡

- 蓝图：`/Game/BP/World/BP_RangedSpawnPoint`。
- 关卡大纲：`Gameplay/RangedSpawnPoints`，现有十张战斗地图各有 `RangedSpawn_01`～`12`。
- 可直接拖动或新增点位；新增点需设置“所属刷怪区域”。圆圈和箭头没有碰撞，游戏中隐藏。
- 对应昼夜地图的候选点位置一致。本次没有移动现有点位或改变地图碰撞。
- 编辑器里的固定点总览表示候选入口，不代表每一波会启用所有点。
- 没有摆点的自定义地图仍兼容原区域刷怪方式。

## 验证

Development Editor 编译通过，近处三点轮换、远点回退、受阻回退、最小安全距离、固定炮台近圈、区域绑定和点位销毁均有定向验证。

十张昼夜战斗地图逐一进入临时运行世界，每张实际生成 36 次地面远程怪、飞行远程怪和远程 Boss，共 360 次出生检查通过，位置都在玩家附近的战斗圈内。测试使用隔离存档，不修改正式进度。

# 敌人受击闪白

打开 `/Game/BP/Enemy/BP_EnemyBase`，点击 **类默认值 → 敌人 → 受击反馈 → 受击材质**。

这里配置一次，现有 13 种敌人子蓝图都会继承。默认已配置 `/Game/GameAssets/Combat/Materials/M_EnemyHitFlash`。新建敌人时请选择 BP_EnemyBase 作为父类；子蓝图若自行覆盖此属性，可点黄色重置箭头恢复继承。

受击材质是临时 Overlay，支持骨骼网格体、静态网格体及附加配饰，不替换模型的原材质槽，不改变模型缩放。默认白色保持 0.02 秒、淡出 0.06 秒，两次闪白最短间隔 0.12 秒。可在基类的“受击闪白”组件中调整时长、颜色、亮度和间隔。对不希望闪白的网格组件添加 `NoHitFlash` 组件标签。

当前静态角色模型启用了 Nanite。UE 5.5 的此 Overlay 路径需要回退渲染，因此组件仅在闪白期间临时开启网格组件的 ForceDisableNanite，结束/回收时恢复原值；不修改静态网格资产的 Nanite 设置。

自定义材质可使用不透明/半透明 Unlit 材质；默认材质提供 `FlashColor`、`FlashIntensity`、`FlashOpacity`、`FlashStartTime`、`FlashHold`、`FlashFade` 参数。普通自定义材质没有这些参数也能临时覆盖，但不会自动渐隐，到时直接撤除。清空基类“受击材质”即可关闭默认闪白。

基类提供 **敌人受击（OnEnemyDamaged）** 蓝图事件，参数为实际生命损失。重写时调用父类保留默认闪白，再添加音效、粒子、动画等表现。这里不应再次扣血或发奖励。

只有实际掉血触发，初始化、回血不触发。专用服务器只记录受击快照；客户端随敌人复制接收表现，多次密集攻击可能合并。对象池回收和复用都会撤销旧覆盖材质及旧计时器。离开网络相关范围后重新出现的敌人不会补播超过 0.5 秒的旧受击。

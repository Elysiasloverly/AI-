# 玩家护盾环绕模型

打开 `/Game/BP/Player/BP_RogueCharacter`，选中组件列表中的 `ShieldOrbit（护盾环绕组件）`，在“护盾环绕”分类中配置：

| 设置 | 用途 | 默认值 |
| --- | --- | --- |
| 护盾静态网格体 | 三个模型共用此网格及其原有材质；不指定时隐藏 | 无 |
| 环绕半径 | 玩家中心到各模型中心的水平距离 | 110 厘米 |
| 旋转速度（度/秒） | 正负值控制方向，0 停止旋转并继续跟随玩家 | 90 |
| 环绕高度偏移 | 相对玩家胶囊中心的高度 | 0 厘米 |
| 模型缩放 | 三个模型的世界缩放 | 0.25 |
| 模型朝向偏移 | 调整模型自身的摆放方向 | 0 |

运行后仅在玩家存活、拥有护盾且当前护盾值大于 0 时显示。项目中的护盾对应 GAS 的 `MaxArmor` 与 `Armor`；两者都必须大于 0。属性或 PlayerState 尚未到达客户端时保持隐藏，护盾耗尽隐藏，恢复后重新显示，濒死或淘汰时隐藏。

三个模型固定相隔 120°。组件在物理更新后跟随玩家位置，用世界空间计算轨道，玩家转向和胶囊缩放不会额外改变配置的环绕半径和转速。它们不产生碰撞、重叠或物理模拟，不参与伤害及导航。

每个有画面的端根据该玩家已复制的护盾属性绘制，不发送逐帧模型变换；各端的装饰旋转相位不保证完全相同。专用服务器不生成模型。护盾耗尽和恢复会复用同三个模型，移除组件或结束游戏时清理模型。

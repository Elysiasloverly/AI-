# 敌人辨识与模型动作

2026-11-03。本轮保留原有角色、扫帚和战斗参数，增加五种角色配饰与静态网格体的轻量动作。Boss 继续使用既有的放大比例、金色头顶符印和地面标记。

## 五种角色轮廓

| 敌人蓝图 | 配饰组件 | 设计 |
|---|---|---|
| `BP_EnemyAuraHealer` | `HealerRune` | 空心莲叶护符，替换原绿方块；表示范围治疗 |
| `BP_EnemyLinkHealer` | `HealerRune` | 细长针形护符，替换原绿方块；表示单体连线治疗 |
| `BP_EnemySkyMoth` | `RoleWings` | 浅蓝蝶形纸翼，与交织弹流呼应 |
| `BP_EnemyWindReaver` | `RolePaperFans` | 浅色尖角扇翼，与折返风刃呼应 |
| `BP_EnemyStarLantern` | `RoleLantern` | 朱色纸灯笼，与星阵合围呼应 |

五个原创模型位于 `/Game/GameAssets/ArtDirection/EnemyRoles/Meshes`，每个 84–156 个三角形，不生成碰撞。可在各敌人蓝图中直接替换、移动、缩放或隐藏配饰。新配饰没有更改现有角色或扫帚的变换。

材质实例位于同目录下的 `Materials`。每种角色有 `Paper` 和 `Trim` 两个实例，可调 `PaperTint`、`SoftGlow`、`Roughness`、`FlutterCm`。纸翼摆动只改变渲染顶点，没有 Actor Tick 或飞行位置变化。治疗护符带 `Rogue.RoleBillboard` 标签，由表现组件朝向本地镜头。

原始 OBJ、模型统计和可复用生成脚本保存在项目的 `ArtSource/EnemyRoles`。

## 模型动作怎么调

打开 `BP_EnemyBase`，选择 **EnemyPresentation／敌人辨识表现** 组件，在“动作”分类调整。子蓝图可以分别覆盖。

| 参数 | 默认值 | 效果 |
|---|---:|---|
| 启用模型动作 | 开 | 关闭后恢复蓝图原始姿态 |
| 移动前倾角度 | 6° | 根据实际移动速度平滑倾斜 |
| 转弯侧倾角度 | 4° | 根据转向角速度侧倾 |
| 移动起伏高度 | 1.8 cm | 移动时的小幅起伏，静止时收回 |
| 攻击后坐距离 | 4 cm | 开火后的短促回摆，约 0.24 秒复位 |
| 受击摆动角度 | 3.5° | 受伤时左右小幅摆动，约 0.20 秒复位 |
| 动作显示距离 | 5000 cm | 超过本地镜头的此距离时恢复原姿态 |

范围伤害网格、内置震荡柱和固定不动的敌人不参与这些模型动作。带骨骼动画的模型也由原动画与网络平滑控制，本轮只处理静态网格。给独立网格添加 `Rogue.NoVisualMotion` 标签可排除它。

同一父子网格链只移动最上层网格，避免子配饰再偏移一次；动作不修改模型缩放。回池、代际变化或关闭功能时恢复原始相对位置与朝向。连续受击有重触发间隔，偏移不会累加。专用服务器不启用表现组件 Tick。

## 攻击、受击和联机

成功的攻击调用 `NotifyAttackFeedback`，沿用原攻击音效通知的单次不可靠多播预算，接收端再分别交给表现组件与音频系统。空音效槽不会阻止动作播放，音频系统不依赖动作组件。

多播继续检查对象池代际、死亡与回收状态，不在新怪身上播放上一轮事件。丢失表现消息可能漏一次回摆或音效，不影响伤害。没有增加逐弹体的动作消息。

受击动作从已有 `OnEnemyDamaged` 事件触发，继续使用现有复制的受击快照；材质闪白和命中粒子保留。护符转向、动作相位等纯外观不做额外复制。

本轮没有增加新的逐帧 Actor Tick，沿用原表现组件 0.05 秒的更新间隔；根网格列表按池代际缓存。静止且无反馈的普通模型跳过变换写入，镜头外超过 0.3 秒或超过显示距离时也停止姿态更新；治疗护符在可见时仍会朝向镜头。外观动作不是完整骨骼动画，后续如果引入有绑定的角色，可在动画蓝图中进一步做肢体动作。

## 验证与开销

Development / DebugGame 均已更新，22 项相关检查通过，五个蓝图的原角色与扫帚变换核对通过。默认战斗镜头另外做实机截图检查。

1920×1080 / DX12 固定负载短测（每组一次，预热 5 秒、采样 6 秒）：白天 200 怪平均帧耗时约 10.13→10.49 ms，黑夜 400 怪约 10.82→11.37 ms；GPU 分别约增加 0.15 ms。该快照保留固定站位，不代表完整移动战斗的性能。第一版存在静止模型的无效更新，已经减少；外观动作仍有一定成本。

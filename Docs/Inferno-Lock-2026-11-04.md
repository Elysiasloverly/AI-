# 火焰柱锁定缩圈

2026-11-04。红色持续光束（焰符·灼光 / HellTower）的每个权威锁定目标现在显示淡金色细圆环和四个短刻度。持续锁定时平滑缩小；默认3秒完成并维持在模型外沿；启用体型适配时，90/45cm是基础配置，实际半径会扩大，避免缩进模型脚底。解除后重新锁定会从大圈开始；多个火焰柱或玩家同时锁同一个敌人只显示一个圈，部分解除不会使剩下的圈突然变大。

## 在编辑器中调整

`/Game/BP/Effects/WeaponLock/BP_HellTowerLockRing` → 类默认值 → 锁定圈：

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| 锁定圈材质 | MI_HellTowerLockGold | 可换自己的材质；默认使用自定义图元数据驱动 |
| 初始半径 / 收缩后半径 | 90 / 45 cm | 自动体型适配后按同一比例缩小 |
| 缩圈时长 | 3 s | 仅改变表现，不改变伤害递增速度 |
| 随目标体型扩大 | 开 | 参考主体短边及胶囊半径，避免缩进身体或被长配饰撑大 |
| 模型外沿留白 | 16 cm | 体型适配时，完成收缩后保留的外沿空隙 |
| 离脚底高度 | 20 cm | 避免地面重叠；飞行怪跟随其脚底平面 |
| 颜色 / 透明度 | 淡金 / 0.95 | 保持极简、能看清的外观 |
| 未收到刷新时保留时间 | 0.65 s | 丢包兜底；实际保留时间也会覆盖光束寿命及少量网络余量 |

火焰柱弹体蓝图 `/Game/BP/Projectiles/BP_RogueHellTowerBeam` → 外观 / 锁定圈 → 持续激光锁定圈蓝图，已经指向新蓝图。置空可关闭这一表现；蓝色激光没有启用。

材质 `/Game/GameAssets/ArtDirection/InfernoLock/Materials/MI_HellTowerLockGold` 的LineWidth控制线宽。母材质是用解析几何生成的，无贴图依赖；源代码保存在 `ArtSource/InfernoLock/InfernoLockRing.hlsl`。自定义材质需遵守CPD约定：0为锁定起始世界时间，1为缩圈时长，2为最终半径比例，3为透明度，4—6为RGB颜色。

## 同步和清理

火焰柱记录每个槽位的持续锁定时间，随现有武器表现批次发送目标Actor、复制的表现代数和锁定时长。没有新增逐发RPC。目标使用已复制的PresentationGeneration识别池化生命周期，不能用各端独立生成的SpawnCycleId跨网络匹配。所属客户端也处理锁定信息，不受“只为远端重放光束”的条件限制。

本地世界子系统合并同一敌人的锁定来源；空闲时不Tick，使用可复用的无碰撞Plane，Actor自身不Tick，材质自行平滑收缩。跟随及失效检测约30Hz；死亡、回池、来源失效、最后一个锁定解除或刷新超时会清理。空闲缓存最多24个，活动目标不会因为这个缓存值被省略。专用服务器不创建圆环。

普通攻击的可选载荷只增加一个存在位；带锁定的攻击额外发送Actor引用、压缩代数和0.01秒精度时间。网络载荷发生了变化，联机各端要使用相同版本模块。伤害、攻击频率、碰撞、地图和商店配置没有随这一表现调整。

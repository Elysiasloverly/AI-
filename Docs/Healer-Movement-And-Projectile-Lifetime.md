# 治疗者移动、治疗量与弹体寿命

更新：2026-10-30。

> 后续已修复停滞，取消治疗量封顶并加入绿色回血数字。当前DT半径为青叶灵1000cm、祈愿妖精750cm，保留用户的恢复比例与间隔；下文为前一次参数对照，最新数值和行为见 [最新说明](Enemy-Healing-Fix-And-Numbers.md)。

## 治疗者如何移动

两种治疗者不再使用围绕玩家的通用Orbit走位。服务器通过 `RogueEnemySupportMovement.cpp` 计算移动，客户端使用已有位置复制。

1. 搜索附近受伤友军，优先剩余生命比例较低者。搜索距离大于治疗半径，因此会主动走向圈外的友军。
2. 尽量到友军背离最近玩家的一侧，在治疗半径内站位；不会为了贴住友军冲向玩家脚下。
3. 任意存活玩家进入紧急距离时，优先后撤。多人距离会一并计算，不仅检查旧的索敌目标。
4. 没有伤员时选择附近有效的满血普通友军跟随，站在其背离玩家的一侧；默认间距300cm。跟随位置尽量与玩家保持900cm，前排友军贴近玩家时不会跟着冲到玩家脚下。没有任何有效友军且已经安全时才原地待命。
5. 每0.4秒优先重选低血量伤员，伤员优先于满血跟随目标；目标回满后转入跟随或救治其它伤员。死亡、归池、换了生成周期或离开搜索范围时立即废弃旧目标；相近目标保留适度滞后，避免来回切换。

单体的实际治疗目标与移动目标分别维护：先接近，进入治疗范围且视线可达才连线和回血；已有有效治疗连线时尽量保持目标。治疗者不自疗、不治疗其它治疗者或生命为零待死亡结算的敌人。

## 在BP里调整移动

打开 `BP_EnemyBase`，选择 `EnemySupport`（敌人治疗）组件，展开 **治疗移动 → 治疗者移动设置**。两种子蓝图继承，也可以分别覆盖：

| 配置 | 默认值 | 作用 |
|---|---:|---|
| 友军搜索半径 | 1800cm | 同时搜索伤员和满血跟随目标；不扩大实际治疗范围 |
| 与玩家期望距离 | 900cm | 空闲时的安全距离目标；支援友军时允许更近 |
| 玩家紧急退避距离 | 500cm | 进入后后撤优先，避免为治疗冲进玩家身边 |
| 友军身后站位 | 治疗半径的0.65 | 尽量在友军背离玩家的一侧治疗 |
| 空闲跟随间距 | 300cm | 没有伤员时，与满血友军保持的后排距离 |
| 友军搜索间隔 | 0.4秒 | 避免每帧扫描；目标失效会提前刷新 |
| 绕障探测距离 | 140cm | 沿移动方向检测现有碰撞，受阻时选侧向路线 |

方向最多每0.12秒重算一次；使用胶囊扫掠做短程绕障，不依赖新增NavMesh，也不提供复杂迷宫的完整路径规划。玩家的期望距离是软目标；同时受到多位玩家或墙角包夹时，选择可行的远离方向。显式把移动模型覆盖为固定不动时，仍尊重该设置。

## 提高治疗量

打开 `DT_EnemyArchetypes` 对应行的 **Healing**，可以修改真实治疗范围与回复量。

| 项目 | 范围治疗：青叶灵 | 单体治疗：祈愿妖精 |
|---|---:|---:|
| 实际半径 | 420cm | 650cm |
| 间隔 | 1秒 | 1秒 |
| 基础回复：调整前 → 当前 | 目标最大生命0.5% → 2.5% | 目标最大生命1.5% → 6% |
| 每目标上限：治疗者最大生命 | 0.8% → 4% | 2.5% → 10% |
| 对Boss的百分比项倍率 | 0.02 | 0.02 |
| 同时目标 | 最多6个 | 1个 |

每跳恢复量 = min(目标最大生命 × 基础回复比例 × Boss倍率, 治疗者最大生命 × 单跳上限)，再限制到目标缺失生命。普通目标不乘Boss倍率。提高回复后，普通目标的基础百分比项提升5倍/4倍；高血量目标仍可能先触发治疗者上限，实际回复不能只看2.5%或6%。

例：第20波，范围治疗对夜雀每跳约3.65生命；单体对重型鬼每跳受上限限制约14.59生命。实际地图7秒观察中，从治疗范围外开始接近，夜雀58.35 → 76.59、鬼128.99 → 201.93。Boss单独降低百分比项，避免按普通目标的6%持续回满巨额血池。

黑夜维持每秒治疗一次，治疗不会跟攻击速度翻倍。生命、速度、数量上限、出现波次和成长曲线沿用前一轮配置。

## 飞行弹体统一30秒

本次更新16个飞行弹体BP的 `Pooling → PooledLifetime`：玩家寒弹、火球、阴阳玉迫击炮，以及全部敌方弹幕（含三种飞行怪弹体），未命中最多存活30秒。

- 飞行怪不再传入3秒、折返时间或预警加固定值作为过期时间，统一读取弹体BP的寿命。
- 星阵预警、风刃折返时刻和迫击炮飞行弧线仍由原攻击参数决定，和30秒过期时间是两件事。
- 命中、落地爆炸、来源死亡/换池周期等原有结束条件仍可提前回收；30秒不会让命中的弹体滞留。
- 激光、御柱是按武器节奏刷新的持续束表现，环绕银刃由武器维持；它们不使用飞行弹体过期计时。
- `InitialLifeSpan` 设为0，交给对象池寿命回收，避免Actor自动销毁绕过池化。激活时重新计时，复用不会继承上次剩余时间。

## 代码与验证

`RogueEnemySupportComponent` 负责治疗及表现，`RogueEnemySupportMovement.cpp` 负责友军选择、站位和退避。原生默认移动与蓝图的 `CalculateArchetypeMovement` 都进入同一逻辑，治疗者不再依赖已缓存的玩家索敌引用。

Development Editor编译通过。23个不同定向用例最终通过：治疗GAS、单跳上限、目标生命周期、多玩家避让、实际移动绕障、四类弹体29秒仍在场/超过30秒回收，以及原有敌人碰撞和飞行攻击相位。首轮暴露蓝图移动查询仍要求玩家缓存，已修复并复测。

当前白天地图PIE也验证了远程寻友、真实回血与退避：玩家距单体治疗者200cm时，1.8秒后约602cm。16个弹体BP重新加载均为30秒；除两行治疗配置外，其余敌人字段及8个数据资产保持一致。未进行完整长局难度压测。

# 灵符·归心

新增的自动攻击武器。灵符在玩家周围环绕待命，发现范围内敌人后飞出穿刺，完成本次命中额度后返回。每张灵符独立出击。无可用目标时继续环绕，不销毁再重生。

## 蓝图外观与飞行设置

打开 `/Game/BP/Projectiles/BP_RogueReturningTalisman`。

| 位置 | 可修改内容 | 当前默认 |
|---|---|---|
| TalismanMesh 组件 | 静态网格体、材质、相对旋转与缩放 | 纸符平面；缩放 `(0.5, 1, 1)` |
| 类默认值 → 灵符 / 环绕 | 半径、高度偏移、角速度、待命尺寸倍率 | 70 cm、35 cm、75°/s、1 倍 |
| 类默认值 → 灵符 / 飞行 | 出击速度、返回速度、穿刺后的越过距离 | 1500、1900 cm/s；150 cm |
| 同上 | 伤害扫掠半径、单次出击超时返回 | 28 cm；30 s |
| 同上 | 返回超时归位 | 8 s；异常情况下自动回到轨道 |
| 类默认值 → 灵符 / 拖尾 | 启用、材质、宽度、保留时间 | 开启；9 cm；约 0.7 s |

飞行时保留 TalismanMesh 在蓝图里保存的缩放。当前纸符在组件中的相对偏航角为 -90°，使符头沿飞行方向。类默认值 → 灵符 / 飞行中的“飞行朝向修正”可补偿替换模型后的俯仰、偏航和翻滚角度。待命尺寸倍率只影响环绕状态；出击、返航恢复模型组件本身的尺寸。伤害扫掠半径独立配置，不会随模型缩放自动改变。修改模型体积时应同时检查扫掠半径。

拖尾由短段曲线网格生成，飞行和返航时显示，环绕时隐藏。更换拖尾材质时需开启材质的 **Used with Spline Meshes**。默认素材位于 `/Game/GameAssets/Weapons/ReturningTalisman/`，纸符贴图源文件位于 `SourceArt/Weapons/ReturningTalisman/`。

## 武器与升级卡

`/Game/Data/Weapons/DT_WeaponConfig` 的 `Talisman` 行配置武器基础数值与弹体蓝图：基础伤害 24、索敌距离 1800 cm、归位后的出击间隔 1.3 s、最短间隔 0.65 s。开局数量为 0，通过本局抽到数量卡获取。

| 卡片 | 枚举 / 表行 | 每选一次 |
|---|---|---|
| 归心符阵 | TalismanCount | 未持有时获得 1 张灵符；之后每次再增加 1 张 |
| 灵符贯阵 | TalismanPierce | 每张灵符单次出击可穿刺的不同敌人数 +1；默认 1 名 |
| 灵符重奏 | TalismanRepeat | 每张灵符单次出击对每名敌人的穿刺次数 +1；默认 1 次 |

例如，贯阵选 1 次、重奏选 2 次，则单张灵符一次出击可攻击 2 名不同敌人，每名最多 3 次，每次造成完整伤害。重复穿刺会实际越过敌人后折返，不会停在敌人身上每帧扣血。返回玩家的路段不额外造成伤害。返回时会补偿玩家与轨道的位移，因此低返回速度也能逐渐接近归位点；超过“返回超时归位”设置则自动归位，避免永久停火。

升级数值和介绍在 `/Game/Data/Upgrades/DT_UpgradeDefinitions`，归属与本局持有前置在 `DA_UpgradeRules`。攻击音效已在 `/Game/Data/Audio/DA_AudioConfig` 添加“灵符·归心”独立插槽，当前留空，可后续自行配置。

## 永久解锁和联机

`/Game/Data/Progression/DA_UpgradeTree` 已添加一整列：

`灵符·归心 → 归心符阵 → 灵符贯阵 → 灵符重奏`

四个节点均为 5 冰砖，按前置顺序解锁。武器节点开放本局首次获取卡；数量卡节点允许持有后继续抽到数量升级。两张专属卡既需要永久解锁，也需要本局实际拥有灵符。升级选卡和商店共用这些筛选规则，各玩家沿用自己的本地解锁进度。

只有服务器生成灵符、索敌和结算 GAS 伤害。客户端显示复制过来的灵符和状态，不额外生成一套，也不重复造成伤害。目标通过对象池的出生周期区分；旧目标死亡、回池或失效后，会换目标或返航。玩家濒死时清理灵符，复活后按当前数量恢复；正常切图由既有属性快照带入下一阶段。

## 实现入口

- `Source/ai/Private/Combat/Weapons/RogueWeapon_Talisman.cpp`：按 GAS 数量维持灵符，提交下一次出击参数。
- `Source/ai/Private/Combat/Projectiles/RogueReturningTalisman.cpp`：环绕、穿刺、返航，线段与敌人胶囊扫掠及拖尾。
- `Source/ai/Private/Debug/Tests/RogueTalismanTests.cpp`：不同敌人数、重复次数、模型缩放、对象池、GAS、永久前置和商店筛选验证。

开发控制台 `Rogue.Test.Talisman 1` 可进入临时演示：暂停刷怪，临时给角色两张灵符及两类专属升级，生成高生命静止靶。该命令不写入永久存档，结束本次运行即可退出演示。联机测试时服务端可用 `Rogue.Test.Talisman 2`，客户端用 `Rogue.Test.ObserveTalisman 2` 检查复制数量与三个状态。

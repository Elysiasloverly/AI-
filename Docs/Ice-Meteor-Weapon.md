# 冰焰·陨星

从原火丸武器改造，内部继续使用 `Rocket` 行、类和节点 ID；原有解锁进度与费用保持可用。

| 配置入口 | 当前效果 |
|---|---|
| `DT_WeaponConfig / Rocket / 天降弹道` | 相对目标召唤高度 1100 cm，水平偏移 650 cm；目标重合时以玩家朝向确定斜坠方位 |
| `RocketSpeed`（下坠速度） | 1900 cm/s，保留弹速加成；随机速度浮动收敛到 ±12% |
| `BP_RogueRocketProjectile` | 基础尺寸 `(1.65, 1.85, 1.65)`；冷白核心和冰蓝焰尾，关闭该组件的 Nanite 以支持半透明冰焰 |
| 陨星齐落 | 首次获得武器；已持有时每轮多召唤 1 颗 |
| 冰焰扩散 | 每张爆炸半径 +90 cm，同时放大飞行球体与焰尾 |
| `BP_CastIceMeteor / BP_BlastIceMeteor` | 独立的冷色起势、白蓝焰心、扩散冲击环和碎冰光；不改变伤害 |

尺寸倍率采用「实际爆炸半径 / DT 基础爆炸半径」。基础半径 280 cm 时，两张扩散卡得到 460 cm 半径和约 1.643 倍外观。只放大外观分支，命中球读取 DT，爆炸伤害读取实际半径；不把模型外观当作伤害范围。回池和重新激活都恢复蓝图尺寸，霜玉不使用这项视觉成长。

服务器广播本次召唤点、下坠方向、速度、爆炸半径和外观倍率。远端客户端使用零伤害表现副本，避免重复结算。冰焰球落地会留下蓝焰，减速地面敌人并持续造成少量伤害；没有冻结。

选卡、商店、永久升级树、游戏内教程、中央音频标签、圆角武器/数量卡/范围卡图标和后续文案刷新源 `Tools/Presentation` 已同步。武器伤害、爆炸基础半径、费用与前置关系沿用原配置。

验证包含 Development Editor 编译、9 项武器与弹体尺寸定向测试、图标绑定检查、临时实机预览和房主/加入者双世界联机检查。临时预览使用独立 QA 存档槽，不改玩家正式存档。

## 落地蓝焰

`DT_WeaponConfig → Rocket → 落地蓝焰` 配置全部战斗数值：默认持续 4 秒，半径为实际爆炸半径的 65%，减速 25%，每秒造成该发攻击伤害的 8%，每 0.5 秒结算。持续伤害按实际间隔计算；默认 48 伤害的陨星留下的蓝焰约为每秒 3.84 伤害。

冰焰扩散同时放大地面蓝焰范围。蓝焰只影响贴近地面的敌人，按敌人脚底高度判断，默认容差 150 cm。落点向下检测真实静态地面，不把蓝焰留在半空或竖直墙面。

同一玩家近乎重合的落点刷新已有蓝焰，避免完全叠在一处重复结算。多个区域的减速取最强值，不相乘。离开范围、区域消失或敌人回池后恢复；不改写敌人 DT 基础移速。

外观在 `/Game/BP/Effects/WeaponCast/BP_IceFlameField`：地面材质、蓝焰材质、火舌高度与簇数都可修改。材质位于 `/Game/GameAssets/ArtDirection/IceMeteor/Materials/M_BlueFlameGround` 和 `M_GroundBlueFlame`。区域无碰撞、无导航影响，已禁用阴影。

服务器创建并复用区域，负责持续伤害和临时减速；客户端复制落点、半径、持续时间和有效状态，负责显示。霜玉及其他复用 Rocket 基类的弹体不自动获得蓝焰；零伤害客户端弹体不创建第二个伤害区域。

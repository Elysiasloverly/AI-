# 战斗特效与冲击节奏精修

2026-11-04。七种施法、五种命中和两种爆炸已经接入新的笔触材质。重点是分开亮核、飞散和余光的时机，让短促攻击有确认，较重爆炸有展开；保留东方符卡、冰晶、焰花和散墨的辨识度。

## 当前效果

| 部分 | 当前处理 |
|---|---|
| 开火 | 更快的起势、短亮核、较克制的碎片飞散 |
| 命中 | 冰晶六向碎裂、暖焰绽开、霜花、银刃切弧、符纸散墨五种笔触 |
| 爆炸 | 放大的火焰/冰霜亮核，延后扩散环，碎片和余光分段收尾 |
| 密集战斗 | 爆炸可回收一个正在播放的普通小效果，优先保留重打击确认；不驱逐其他活动爆炸 |
| 普通退治 | 碎片略微错峰散开 |
| Boss退治 | 延迟0.08秒的第二道散环，以及持续0.32秒的本地轻微镜头回弹 |

镜头只对距离退治点2200cm内的本地玩家生效，从400cm开始衰减；默认强度0.55。连续事件取较大强度，不累加、不延长当前回弹。只修改本帧视角的少量FOV、Pitch、Roll，结束后禁用修饰器；不写玩家控制旋转、Actor位置或游戏时间。

## 在蓝图中调整

| 入口 | 参数 |
|---|---|
| `/Game/BP/Effects/WeaponCast/BP_Cast*` | 运动节奏=施法起势；亮核尺寸、扩散环尺寸、碎片飞散距离 |
| `/Game/BP/Effects/WeaponImpact/BP_Impact*` | 运动节奏=命中碎裂；同上三项尺寸/距离 |
| `/Game/BP/Effects/WeaponCast/BP_BlastEmber`、`BP_BlastGlacier` | 运动节奏=爆裂扩散；亮核2.35、扩散环1.45、飞散距离1.7 |
| `/Game/BP/Effects/BP_EnemyDefeat` → 退治特效 / Boss | Boss退治镜头回弹开关、镜头回弹强度 |
| 玩家各弹体蓝图 → 开火特效 / 爆炸中心特效 | 原有颜色、整体大小、时长、碎片数、最短间隔 |
| `/Game/BP/Enemy/Common/BP_EnemyBase` → 受击反馈 | 原有按武器区分受击特效与闪白配置 |

`Rogue.VFX.CameraKick 0` 可以立即停用全局镜头回弹，1为启用。没有新增设置菜单条目。

新材质集中在 `/Game/GameAssets/ArtDirection/CombatFeel/Materials`，母材质为 `M_CombatStroke`，各蓝图使用独立 `MI_*`。`Style`区分笔触，`FxKind`区分施法、命中与爆裂，`Energy`调亮度；`Shape`、`Progress`、`Seed`、`Tint`、`Opacity`由表现Actor驱动。源码保存在 `ArtSource/CombatFeel/CombatStroke.hlsl`。

所有形状由材质计算生成，没有新贴图、动态灯光或场景捕捉。固定随机种子和局部朝向只在激活时写入；进度、尺寸和碎片运动沿用原有受限Tick。普通活动上限48、高负载16、池容量64及5000cm镜头距离裁剪保持；Boss消散仍使用独立受限实例池。

## 验证与实际限制

Development Editor编译成功。23项不同的定向检查通过，最后减少固定参数重复更新后又复核3项池化/进度/优先级检查。包括真实GAS伤害链路、复用重置、快照去重、碰撞隔离、池满时爆炸仍可见，以及镜头按时恢复。部分测试世界有缺少正式刷怪区的已有提示，没有失败。

15个表现蓝图已保存；92份原数据、地图、音效、界面和玩家弹体资产前后哈希一致。声音保持原配置。没有新增逐次特效RPC，沿用原有本地表现和受击快照。

四组慢速摆放预览覆盖起始、中段、尾段和结束，所有效果均回收到0。白天和黑夜正常开局的状态观察均运行过；但本轮这组PIE普通开局截图抓到了编辑器视口，不能作为正常战斗画面证据，未列入交付图片。黑夜静止玩家在约5秒时死亡，记录按实际结果保留。`Dense-Battle.png`来自独立游戏进程的固定压力场景，是真实渲染与武器开火，但敌人与玩家负载经过控制，不能当作正常局难度。

没有重新进行完整百波或双进程联机对局；镜头回弹的数值与恢复由定向检查覆盖，不把静态图当作镜头动态验证。

## 固定负载开销

1920×1080，红魔钟庭黑夜，400敌人、20张符纸、实际武器开火，预热5秒后每次采样8秒。三个版本依次为修改前、初次增强、减少重复更新后的最终版。

| 版本 | 样本帧 | 平均帧 ms | P95 ms | 游戏线程 ms | GPU ms | 半透明GPU ms |
|---|---:|---:|---:|---:|---:|---:|
| before | 736 | 10.88 | 11.47 | 7.59 | 9.67 | 0.222 |
| after | 704 | 11.37 | 12.44 | 8.40 | 9.98 | 0.232 |

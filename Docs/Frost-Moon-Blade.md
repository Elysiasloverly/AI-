# 冰刀·霜月

冰刀是扇形范围横斩武器，只持有一把。获取后，刀柄在上、刀尖朝下悬于身后；有近处目标时，飞到目标靠玩家的一侧，水平横斩，再回到身后。横斩过程不持续追着目标跑，也不能无限离身。

## 编辑入口

| 改什么 | 位置 |
|---|---|
| 伤害、攻击间隔、索敌范围 | `/Game/Data/Weapons/DT_WeaponConfig` → `FrostBlade` |
| 刀长、碰撞宽度、基础离身距离、横斩角度、三段动作耗时 | 同一行 → 冰刀·霜月 → 冰刀战斗参数 |
| 剑波伤害倍率、速度、寿命、碰撞尺寸、多波扇形角 | 同一行 → 冰刀战斗参数 → 剑气 |
| 刀的模型、材质、组件缩放、身后偏移、漂浮、出刀闪光 | `/Game/BP/Projectiles/FrostBlade/BP_RogueFrostBlade` |
| 剑波模型与材质 | `/Game/BP/Projectiles/FrostBlade/BP_RogueFrostSwordWave` |
| 卡片名称、说明、每张增量、选取上限 | `/Game/Data/Upgrades/DT_UpgradeDefinitions` → 五个 `FrostBlade*` 行 |
| 冰砖价格、永久前置、节点文本 | `/Game/Data/Progression/DA_UpgradeTree` → 五个 `FrostBlade` 节点 |
| 音效插槽 | `/Game/Data/Audio/DA_AudioConfig` → 武器 → 冰刀·霜月（中央系统管理的三种轻风 / 冰鸣变体） |

外观放在 BP，战斗数值放在 DT。组件缩放是美术基准，不会偷偷改写伤害碰撞；升级卡在此基础上同步扩大模型和 DT 定义的命中范围。改表后重新开始游戏，运行中的武器使用开局读取的行副本。

## 卡片与永久解锁

永久树按 `冰刀·霜月 → 霜刃延展 → 霜月出鞘 → 霜月重叠 → 霜月盈空` 逐级开放，每个节点 5 冰砖。冰刀武器节点解锁后，每局开场自动装备一把，无需抽取获取卡，也不再刷新该获取卡。后续四种专属卡仍需分别永久解锁，再在本局选卡或商店中获得。

| 卡片 | 本局效果 | 稳定类型 |
|---|---|---|
| 冰刀·霜月 | 永久解锁后每局自动装备一把，不进入选卡或商店 | `FrostBladeCount` |
| 霜刃延展 | 当前每选一次，刀的尺寸增加基础值的 25%；横斩范围和伤害随尺寸提高 | `FrostBladeSize` |
| 霜月出鞘 | 横斩时开启一道穿透剑波，只需选一次 | `FrostBladeWave` |
| 霜月重叠 | 每次横斩额外放出 1 道剑波 | `FrostBladeWaveCount` |
| 霜月盈空 | 剑波模型和水平命中尺寸增加基础值的 20% | `FrostBladeWaveSize` |

剑波数量、大小卡还要求本局已选过“霜月出鞘”。永久解锁、选卡与商店都沿用各玩家自己的档案；新增枚举追加在末尾，保留已有枚举数值与存档节点键。

## 初始数值与判定

- 横斩基础伤害 22，额外攻击力按 0.8 倍计入，再应用该行伤害上限。攻击间隔 1.5 秒，最短 0.7 秒。
- 刀刃基础伤害长度 190 厘米，基础命中球半径 20 厘米，刀柄的基础离身距离 330 厘米。通用攻击范围加成会同时扩大索敌与实际出击距离，不再设 520 厘米等武器上限。
- 靠近、挥刀、归位分别为 0.16 / 0.26 / 0.22 秒。一次横斩对同一轮出生的敌人只结算一次，可以同时斩中多个敌人；不会选择墙后的目标。
- 剑波伤害为本次横斩的 40%。基础速度 1200 厘米/秒，基础寿命 30 秒。
- 剑波基础模型宽 **480 厘米**，命中半宽 **240 厘米**，前后碰撞半厚 55 厘米。模型为浅弯月，白蓝前缘与蓝色尾部，不是整圆光环。
- 剑波穿透敌人，对每名敌人每轮出生最多命中一次；碰到地图的 WorldStatic 碰撞或达到寿命后消失。剑波只攻击敌人。
- 尺寸卡扩大水平宽度与前后厚度，竖直命中容差保持 DT 的值，避免多次尺寸升级后误碰地面。空闲剑波由池复用，只保留至多 24 个空闲实例，不限制正在飞行的剑波数量。

伤害由服务器结算。冰刀复制动作阶段，剑波复制发射状态，各端本地重建运动；不需要每帧同步位置。玩家死亡移除冰刀，已经发出的剑波继续遵循碰墙和寿命规则。切图成长快照会保留五种新属性。

## 美术源文件

模型与生成源保存在 `ArtSource/Weapons/FrostBlade`。精修版冰晶刀 478 三角面、冰屑 72 三角面、剑波 272 三角面、横斩残影 96 三角面。UE 素材在 `/Game/GameAssets/Weapons/FrostBlade`，各材质可以单独替换。刀模型以本地 +X 为刀尖方向，柄部为原点；待命姿态由 Actor 转成刀尖朝下。

验证命令：`Automation RunTests Rogue.Gameplay.FrostBlade`。完整结果与实机截图见工作区 `outputs/Frost-Blade-2026-11-04`。

## 2026-11-04 美术精修

新版模型、材质与生成源位于 `/Game/GameAssets/Weapons/FrostBlade/Refined`、`ArtSource/Weapons/FrostBlade/Refined`。模型在原蓝图里更换，刀长与基础剑波宽度继续匹配 DT，原有蓝图类和卡片标识保持可用。

- `BP_RogueFrostBlade`：晶面与白刃、六角雪花护手、冰屑；`HoverFollowSpeed`、`HoverSwayDegrees` 调待命追随和轻摇，`TipClearance` 在巨化后抬高待命位置，`AfterimageDuration` 调收刀余晖。刀尖高度自动适配只影响待机姿势，横斩判定仍由 DT 定义。
- `SlashTrail` 只显示刀已经扫过的部分；`Afterimage` 短暂保留最后一道刀光，然后淡出，避免整片扇面瞬间出现、瞬间清空。
- 剑波的前缘、细流光和少量冰屑合并在同一个网格中。`Wave.hlsl` 调波体，`Trail.hlsl` 调刀光；`Energy` 与 `Opacity` 可直接在材质里调整。材质渐隐不改变实际存活时间。
- 真正进入横斩阶段才触发音效、出刀闪光与 HUD 跳动；取消靠近动作会保持安静。音量仍由设置里的音效分类控制，声音只在 `DA_AudioConfig` 配置。
- 冰刀和剑波使用独立的 `FrostBlade` 命中风格（索引 6）；`BP_CastFrostMoon` 和 `BP_ImpactFrostMoon` 分别位于武器施法 / 命中特效目录。所有敌人的新映射已补齐，不覆盖其他武器风格。
- 碰墙结束会同步结束位置，播放一次轻冰屑；重复状态接收不会重复生成。超时结束在最后约 0.18 秒淡出。

本轮还核验了实际 GameMode / Character 引用、实际商店报价、本局前置、巨化、壁面结束、双进程命中身份与尺寸复制，以及新 Pawn 的切图属性恢复。切图后的 1.399999976、1.600000024 是单精度表示误差，比较使用浮点容差，不影响 1.4 / 1.6 倍的实际效果。

## 通用范围与冰图可读性更新

通用攻击范围加成现在同时增加索敌和冰刀的实际出击距离。冰刀不再使用“基础离身距离＋刀长”封顶，也不使用通用 `MaxRange` 字段封顶；当前玩家通用范围加成上限为 -1（不限）。

`索敌距离 = max(0, DT.Range + 通用范围加成) + 基础刀长 × (专属尺寸倍率 - 1)`。
出击时的刀柄可离身距离取“基础离身距离＋通用范围加成”和“索敌距离－当前刀长”的较大值，确保选到的远处敌人能被实际斩中。通用范围不把刀或剑波直接变大；对应的专属大小卡继续负责模型和命中尺寸。

剑波使用 `Refined/Materials/M_MoonWave_Outlined`，白色描边配细深蓝外缘，冰面上保留对比。`OutlinePixels` 默认 3，`InkPixels` 默认 0.85；能量和透明度仍可在材质里调。网格宽度、伤害、碰撞与 30 秒寿命没有因描边改变。

## 扇形范围与基础攻击（2026-11-05）

横斩中段会统一结算刀前方的扇形区域，命中其中全部有效敌人，每只敌人每次横斩只受伤一次。刀的长度和横斩边缘宽度一起随尺寸增长；区域判定会包含敌人胶囊边缘，但排除后方、超距、相隔过高以及被地图碰撞遮挡的目标。敌人之间不会遮挡这次区域查询，低帧率跨过整段横斩也会结算一次。

伤害 =（`DT_WeaponConfig.FrostBlade.Damage` + 玩家攻击加成 × `FrostBladeCombat.AttackPowerScale`）× 冰刀尺寸倍率。

玩家攻击加成同时包含永久升级树的基础攻击、玩家初始攻击配置和局内攻击卡。当前武器基础伤害 22、攻击系数 0.85；保留你在表中的配置。霜刃延展当前每张增加 25% 基础尺寸，因此两张为 1.5 倍尺寸，范围与合并后的伤害一起变为 1.5 倍，不是连续乘 1.25。可在升级定义表调整每张增量。

尺寸成长不新增上限；已有显式 `MaxDamage` 配置仍作为最终上限，当前为 -1（不限）。剑气沿用“相对横斩伤害倍率”，当前 0.4，因此也会继承基础攻击与冰刀尺寸带来的伤害增长；剑气自身大小卡仍只调整剑气外观与命中范围。

尺寸和基础攻击均由服务器通过现有 GAS 快照结算。升级树、选卡、商店文案已同步；永久解锁后每局自动装备一把的规则继续生效。

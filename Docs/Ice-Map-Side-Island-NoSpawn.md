# 冰湖侧平台禁刷区

2026-11-04。白天与黑夜冰湖都将截图圈出的左下建筑平台及近端桥段加入刷怪排除区域。

入口：打开 `Battle_MistyIceLake_Day` 或 `Battle_MistyIceLake_Night`，选择 `EnemySpawn_PlayableOutline` → `ExcludedAreas`。原有两个水面内孔保留，新平台是第三个排除多边形；点按世界 XY 存储。

区域按当前 `SM_Map02_Environment` 的实际变换定位，不依赖可移动商店的位置。模型局部基准对应原场景 x=[-36,-12] 米、y=[-36,-18] 米；地图平移、旋转和缩放已经转换为各地图的世界坐标。商店实例、模型、通路、外侧刷怪轮廓与空气墙保持原样。

排除区域对所有高度生效，普通怪、Boss 与飞行怪共用原刷怪区域验证入口；取消刷怪不限制玩家通行，也不额外添加碰撞。

两张图保存后重新加载，区域采样在半径 0 / 34 / 80 / 140 厘米下均被拒绝，中央控制点仍允许刷怪。实际世界坐标与核验结果见工作区 `outputs/Frost-Range-Ice-2026-11-04/Maps-And-Material.json`。

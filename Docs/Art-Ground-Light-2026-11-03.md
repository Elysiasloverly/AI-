# 地面与昼夜光影精修

2026-11-03。本轮针对大块纯色地面、过长的黑影和夜间明暗层次，已保存到五种主题的十张战斗地图。没有修改玩法数值。

## 场景变化

| 场景 | 本轮处理 |
|---|---|
| 雾湖冰洲 | 冰面增加静止薄霜、冰层云纹和细微凹凸；使用较低粗糙度，保留清楚的弹幕背景 |
| 红魔钟庭 | 压低紫红地面的饱和度，增加旧石矿物纹理与粗糙度变化；保留原有钟盘金线 |
| 樱庭神社 | 石坪、石阶加入低对比磨损与色斑，保持原模型的砖缝和花瓣 |
| 竹林月径 | 石地加入偏青灰的风化层次，保留原有竹叶、苔痕和法阵 |
| 森林 | 保留原有苔土、路径遮罩，叠加细微地表颗粒；石质部件使用统一绘本材质 |

所有图的地表细节采用世界坐标采样；冰纹和石纹不滚动、不改变网格顶点或碰撞。水体沿用原材质，普通敌方弹幕也沿用原外观。

## 材质怎么改

内容浏览器打开 `/Game/GameAssets/ArtDirection/GroundLight/Materials`。

- `M_PaintedGroundLayers`：受光的地表母材质，包含底色、分层、粗糙度和世界空间微凹凸。
- `MI_Ground_Ice_pale_blue`：冰面。
- `MI_Ground_Crimson_marble`：钟庭石面。
- `MI_Ground_Paving_*`：不同石坪和铺地。
- `MI_Ground_Garden_earth`：土壤；`MI_Ground_Stone_warm`：暖色石材。
- `MI_Ground_Frost_masonry`：结霜石材。
- `M_ForestGroundLayers`：森林的独立材质，保留原有多层路径遮罩。

| 实例参数 | 作用 |
|---|---|
| `BaseTint` | 主要底色 |
| `LayerTint` / `LayerStrength` | 斑驳层颜色与强度；先调强度，避免地面抢过弹幕 |
| `DetailStrength` | 手绘颗粒对比 |
| `BaseRoughness` | 越小越有细微反光；冰面当前 0.44，钟庭 0.64 |
| `ReliefHeightCm` | 仅用于光照法线的凹凸强度，单位厘米；不改变高度或碰撞 |
| `Specular` | 非金属表面的反射强度 |
| `SurfaceKind` | 0 普通石面、1 薄霜冰面、2 土壤、3 旧大理石；通常不用修改 |
| `Scale0.0` / `Scale0.37` | 世界坐标的底纹 / 细纹采样频率，越大纹理越密 |

母材质复用已有 `T_PaintedStone` 手绘纹理，额外霜纹与石纹由静态材质计算，没有增加外部贴图依赖。

## 灯光怎么改

在各自的 Day / Night 地图中编辑方向光、SkyLight、PostProcessVolume 和已有点光源。以下是本轮保存值：

| 项目 | 白天 | 黑夜 |
|---|---:|---:|
| 方向光强度 | 3.15 | 0.20 |
| 方向光 Pitch / Yaw | −48° / −25° | −57° / −35° |
| 天光强度 | 0.82 | 0.58 |
| 曝光补偿 | −0.10 | −0.80 |
| 后期对比度 | 1.025 | 1.025 |
| AO 强度 / 半径 | 0.28 / 34 | 0.28 / 34 |

本轮用更高的月光角度缩短拖尾投影，用冷色天光和较轻的环境遮蔽降低黑块感。既有灯笼改为暖色、较大的光源半径，保持不投影，没有新增灯光数量。

项目当前使用传统阴影贴图，未开启虚拟阴影贴图。本轮没有把 `Source Angle` 当作动态阴影柔化保证；阴影的改善主要来自方向、环境补光和接触明暗控制。

游戏保留地图灯光配置。不要为了提帧开启会覆盖环境的旧“启用场景优化”设置；该设置会更改主灯、隐藏局部灯与后期效果。运行时方向光已抽查与保存值一致。

## 验证范围

- 十张地图重新加载，核对 GameMode、商店、四个 PlayerStart、刷怪区域、边界位置。
- 六个网格资产共 24 个材质槽更新，独立碰撞代理引用保持一致。
- 默认镜头下检查十张昼夜地图，未修改镜头距离、角色比例、战斗逻辑或存档。
- `Rogue.World.MapCollection` 三项现有检查通过，其中一项报告一条资源加载警告，无失败。
- 1920×1080、DX12，固定 200 / 400 怪，各预热 5 秒、记录 6 秒的一次短测：GPU 平均耗时约 8.96→9.01 ms / 9.52→9.63 ms。这是固定负载快照，不是完整关卡性能结论；帧耗时的轻微下降不应解释成优化收益。

本轮只改资产，不涉及 C++ 模块变更，因此无需重编译 Development / DebugGame。重新打开编辑器即可加载。

# 护盾与环绕武器精修

2026-11-03。本轮处理角色周围近距离装备的遮挡，以及符纸返回时拖尾突然截断的问题。

## 本轮表现

- 护盾保留四个原材质槽的冰纹、法线与颜色，使用独立半透明副本。出现时约 0.16 秒淡入，护盾数值下降时出现短暂冷色脉冲。
- 护盾与待命符纸在镜头前方遮住自己的玩家时，局部透明度降低；每个玩家单独传入自己的位置，队友不会共用一个全局中心。
- 符纸只有待命阶段使用独立表现材质。出击与返回使用蓝图原组件材质，归位后重新应用待命材质。
- 返回时保留原有世界空间尾迹，并按原 `TrailLifetime` 老化、缩细后消失。新一轮出击清空旧记录，避免跨越待命轨道拉出长线。
- 银刃仅把旧六边形覆盖材质换成细边冷光，保留原主体材质。

## 编辑入口

| 编辑位置 | 配置 |
|---|---|
| `BP_RogueCharacter → ShieldOrbit` | `护盾表现材质（按槽位）`，四个材质实例；清空数组即可使用所选网格自带材质 |
| `BP_RogueReturningTalisman → 类默认值 → 灵符／环绕` | `待命表现材质（按槽位）`；清空后待命也使用原组件材质 |
| `BP_RogueOrbitingBlade → Mesh1` | `Overlay Material = M_SilverEdgeBreath` |

新材质集中在 `/Game/GameAssets/ArtDirection/PlayerOrbit/Materials`。

`MI_ShieldOrbit_0..3` 和 `MI_Standby_0` 保留各自原材质的参数，并增加 `OrbitOpacity`、`FocusHeightCm`、`FocusRadiusCm`、`FocusSoftnessCm`、`FocusMinimumOpacity`。默认遮挡中心在玩家位置上方 30 cm，软化半径 48 cm，过渡宽度 28 cm，最低系数 0.16；护盾基础透明度系数 0.72，符纸 0.78。它们是颜色表现参数，不改变模型或伤害范围。

银刃母材质的 `EdgeTint`、`EdgeOpacity` 调整边缘颜色和强度；原银刃逻辑继续驱动 `GlowPulse`。

## 运行与性能边界

护盾的可见条件仍为：存在护盾上限、当前护盾大于零、角色存活且组件启用。当前值归零立即隐藏。每个本地护盾读取本玩家 GAS 属性，以自定义图元数据传入着色器；没有新增逐帧 RPC、动态灯或动态材质实例。专用服务器不创建护盾表现网格。

为支持半透明和覆盖层，这些装备在使用新表现材质时关闭组件 Nanite；符纸离开待命后恢复原 Nanite 开关。半透明可能存在排序与过度绘制成本，仍需在最终大量装备的实战镜头下关注。

符纸继续使用原有 16 个尾迹段，没有增加尾迹段数量、延长持续时间或增加 Actor。角色与武器的模型、原组件材质槽、相对变换，以及护盾/符纸的半径、速度、偏移均已与修改前记录对照。

## 验证

Development / DebugGame 编译完成，18 项定向测试通过，覆盖护盾显示条件、无碰撞、局部数值脉冲、空盾隐藏、符纸真实出击/返回、原材质恢复、归位后的尾迹消散及同种武器索敌分配。

樱庭白天关卡完成近景、默认镜头、受击、符纸出击、返回及尾迹结束的分阶段预览。预览暂停了刷怪、移动与自动开火；银刃固定在轨道位置，用于检查材质，不代表完整战斗录像。预览中护盾会自动恢复，因此标为 `ShieldEmpty` 的早期图片不能作为零盾隐藏的证据；零盾条件由定向测试验证。

这轮没有重新进行双客户端完整对局，联机判断沿用既有属性和符纸阶段复制。

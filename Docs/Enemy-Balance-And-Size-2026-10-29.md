## 计算依据与样本

每跳治疗 = min(目标最大生命 × 恢复比例 × Boss修正, 治疗者最大生命 × 自身上限)，再限制到目标缺失生命。Boss修正仅作用于第一项；触发自身上限后，继续降低Boss修正未必降低最终回复，不能只看倍率就推断实际恢复。

下表用曲线表真实生命值，假设同波2个范围治疗者和1个单体治疗者同时为Boss回血。它是配置上限内的叠加场景，不代表Boss必定带着三名治疗者出现。表内寒弹基础DPS=24/0.7≈34.29，仅作为未升级对照，后期实际武器配置需另测。

| 波次 | 普通生命曲线 | Boss合计回血/秒：原 → 当前 | 当前相对基础寒弹DPS |
|---:|---:|---:|---:|
| 20 | 153.56 | 7.99 → 5.74 | 16.7% |
| 36 | 307.62 | 16.00 → 11.49 | 33.5% |
| 40 | 357.73 | 18.60 → 13.36 | 39.0% |
| 60 | 661.75 | 34.41 → 24.72 | 72.1% |

例如第40波极端叠加场景约18.60 → 13.36生命/秒，减少约28.2%；治疗者不会互相治疗，优先击杀支援怪可以直接停止这部分回复。百分比成长仍随曲线增加，不能据此保证无限波数下的难度。

固定法阵未减伤DPS = 同波敌人伤害 × 法阵倍率 / (基础间隔 / 黑夜攻速倍率)。以下针对普通地藏，使用其既有1.55类型伤害倍率。实际扣血仍会经过玩家护甲、减伤和无敌状态。

| 波次 | 场景 | 每跳伤害：原 → 当前 | 法阵DPS：原 → 当前 |
|---:|---|---:|---:|
| 12 | 白天 | 5.52 → 3.16 | 7.36 → 3.51 |
| 20 | 白天 | 7.17 → 4.10 | 9.56 → 4.55 |
| 36 | 黑夜 | 10.47 → 5.98 | 27.92 → 13.30 |
| 40 | 黑夜 | 11.29 → 6.45 | 30.12 → 14.34 |
| 60 | 黑夜 | 15.42 → 8.81 | 41.11 → 19.58 |

同一攻击值下，法阵持续DPS约下降52.4%。第40波单个普通法阵约14.34 DPS；若3个法阵重叠仍约43.03 DPS，应离开重叠区域。用户现有法阵直径约1857cm；没有缩小法阵来掩盖伤害问题。按玩家基础移速650cm/秒，从圆心直线离开半径约需1.43秒（不计阻挡），这段时间的承伤也比原配置明显降低。

## BP模型尺寸

按模型主体高度测量，保留各模型自身长宽比例、朝向与脚底高度，不包括扫帚、头顶提示和法阵。修改保存在各敌人的BP组件，运行时不强制统一普通模型大小。

| 类型 | 主体高度 |
|---|---:|
| 普通怪与两种治疗怪 | 144cm |
| 三种飞行怪 | 140cm |
| 鬼（重型怪） | 160cm |
| 地藏（固定怪用户模型） | 150cm |
| Boss | 对用户模型额外乘1.5，例如144 → 216cm |

青叶灵原98.6cm、祈愿妖精原91.5cm，现在均为144cm。三种飞行怪从95–100cm提升到140cm。Boss放大回池后恢复，避免复用累积倍率。模型和材质资源、扫帚比例、法阵尺寸与碰撞胶囊均沿用原配置。

在各敌人BP的 `Cube` / `HealerBody` / `FlyingBody` 组件中调整模型；Boss附加倍率在 `BP_EnemyBase` 的“敌人辨识表现”组件。治疗参数在 `DT_EnemyArchetypes.Healing`，生命/移速倍率在 `DA_GameBalance.EnemyBalanceRows`，法阵伤害在基类“固定敌人法阵伤害”组件。绿色圈与连线仍是独立BP，见 [配置说明](Enemy-Roles-And-Visibility.md)。

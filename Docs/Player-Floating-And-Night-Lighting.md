# 玩家漂浮与神社夜景

## 玩家漂浮组件

在 `BP_RogueCharacter` 组件树中选中 `FloatingMotion`（漂浮组件，原生类型 `RogueFloatingComponent`），调整独立的「漂浮」设置。`Visuals` 现在只负责挂接模型。

| 参数 | 当前值 | 用途 |
|---|---|---|
| 漂浮目标 | Visuals | 选择同一个 Actor 上的外观组件；不会让角色根胶囊漂浮 |
| 启用漂浮 | 开启 | 控制上下漂浮 |
| 漂浮幅度 | 4 cm | 原位置上下各偏移 4 cm |
| 漂浮周期 | 3.2 s | 一个完整上下周期 |

Sphere 等模型挂在 Visuals 下。FloatingMotion 只给目标增加相对位置偏移，保留模型、材质及缩放。胶囊和相机不随之漂浮。关闭漂浮、切换目标、停用或销毁组件时，会扣除该组件施加的偏移。运行时可调用组件的 `SetFloatingEnabled`；原 Visuals 上同名旧接口保留为兼容转发。

组件可单独添加到其它 Actor，通过「漂浮目标」选择模型挂接点。它不复制逐帧偏移，专用服务器不执行漂浮 Tick；编辑器静止视口不播放漂浮。

## 玩家转向与俯仰

在 `BP_RogueCharacter → TurnSmoothing`（转向平滑组件）调整「转向跟随速度」，当前为 **10**。降低会更柔和，提高会更跟手；建议先在 8–14 之间调节。

目标为 Visuals，采用最短旋转路径和随时间平滑跟随。角色胶囊的移动与旋转仍由 CharacterMovement 处理，外观平滑不会增加移动输入延迟。该组件可独立开关、停用或更换目标，并保留蓝图模型原始相对旋转与缩放。

玩家类默认值中的相机俯仰范围已由 -75°～-35° 放宽到 **-85°～-10°**。

## 当前地图夜景

地图：`/Game/GameAssets/StarterContent/Maps/Minimal_Default`。以当前森林、鸟居、灯笼和宝箱布局配置蓝紫色月光及暖色局部光，保留中央战斗区的可读性。

在关卡大纲「灯光/夜晚」调整：

| 对象 | 当前配置 |
|---|---|
| 夜景_月光 | Movable Directional Light，强度 0.35，冷蓝紫色，保留阴影 |
| 夜景_天空补光 | Movable Sky Light，强度 0.14，指定引擎环境 Cubemap 并加冷色调 |
| 夜景_淡蓝薄雾 | 高度雾密度 0.0025，最大不透明度 0.22，轻微蓝紫色；不启用体积雾 |
| 夜景_曝光与色调 | 全局后处理体积，手动曝光，曝光补偿 -0.45，关闭物理相机曝光，轻微冷色调与 Bloom |
| 石灯笼与鸟居 | 六个暖色 Point Light，650–900 lm，半径 1800 cm；关闭局部动态阴影以控制成本 |
| 夜景预览相机 | 用于查看整张地图，不自动接管玩家相机 |

天空材质：`/Game/GameAssets/Environment/Night/MI_NightSky`，父材质 `M_NightSky`；调整材质实例的 `NightSkyColor` 可以修改背景颜色，不会影响引擎共享天空材质。

本次保留森林模型、PlayerStart、刷怪区域及其它已有非灯光 Actor 的变换。没有修改森林模型的材质资产，也没有重新加入此前删除的商店或旧竞技场。

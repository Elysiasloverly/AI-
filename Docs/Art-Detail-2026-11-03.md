# 美术细节精修：拾取物、标记、牌签与交互

本轮继续统一到绘本幻想乡的表现：收掉混用的银河与全息效果，让经验、Boss、飞行位置、危险预警各自清楚；卡片和飘字增加细小、连续的动作。新增两份自制模型，不引入外部素材包。

## 具体改动

| 范围 | 更新 |
|---|---|
| 经验拾取物 | 原球体换为 12 三角面的六棱灵力结晶，增加清楚的亮面与淡青轮廓，材质中微浮动约 3 cm；银河外层改成极弱的淡青光晕 |
| 经验球灯光 | 原先每颗 780 强度的点光源改为 0，改用结晶自身材质表现亮度；真实激活的三颗拾取物均检查为 0 |
| Boss 标记 | 基础红色立方体换为空心金色符印与折纸尾，共 132 三角面；标记缩放由 0.3 调为 0.5，面向本机镜头；地面光环换成细线与花瓣刻度 |
| 飞行敌人 | 地面标记改成低对比的四向定位纹，避免像额外攻击范围 |
| 天坠预警 | 清楚的外边界、逐渐收拢的内圈、疏刻度与少量底色；进度按本机还原的攻击时间推进，触地之前外边界始终保持显示 |
| 商店场景 | 全息方块光效改为微弱暖灯色；巨大、背面反字的 SHOP 改为屏幕朝向的“香霖堂”圆角牌签，制作成独立 WBP |
| 商店卡片 | 说明区从 88 增至 114，价格移到独立下部区域，加入细分隔线；卡高增至 270，六张卡仍分两行，页面相应留出底部操作空间 |
| 商店与升级卡 | 悬停轻微放大、按下轻微压缩，平滑恢复；只改变渲染变换，不改布局占位与按钮回调 |
| 伤害 / 治疗数字 | 平滑淡入、短促强调、分左右小幅散开、减速上浮后淡出；文字居中，阴影移到右下；上浮不再随世界投影缓存阶梯式变化 |
| 十张战斗地图 | 阴影中增加少量冷色、高光保留微暖色，AO 半径由 55 缩至 42；保留现有曝光、雾、主光与各主题材质 |

地图中商店、出生点、刷怪轮廓与空气墙的 Actor 变换逐张核对一致。现有敌人弹幕材质与几何继续沿用；本轮未用美术调整改写伤害、拾取、治疗或刷怪规则。

| 卡片动效参数 | 悬停倍率 `1.018`、按下倍率 `0.987`、过渡速度 `18`；自己制作根控件动画时，可关闭 `启用柔和交互` |
| 卡片排版 | 保留现有 `Text_Title`、`Text_Desc`、`Text_Cost`、`Button_Select` / `Button_Offer`；分隔线为 `TitleHairline`、`CostHairline` |

`ArtSource/Detail` 保存了两份 OBJ、面数记录和模型生成脚本。源模型单位为厘米，导入后的结晶高度核对为 100 cm；实际显示仍跟随 BP 子组件缩放与原有经验合并外观倍率。

## 实现边界

卡片共用 `URogueCardMotionWidgetBase`。动效基于原有渲染变换追加小幅缩放，移除控件时恢复原值；禁用卡片回到原尺寸，不更改购买、选卡、焦点或音效绑定。布局占位保持不变，避免悬停导致相邻卡片移动。

飘字仍使用原来的数量预算、文本与世界投影缓存。每个数字在本机分配一个独立的微小横向偏移，绘制时计算屏幕运动；不访问玩法随机数。回血的小数格式与实际数值保持原逻辑，没有把低于 1 的回复量显示成整数 1。

天坠材质使用 `WarningStartTime` 与 `WarningDuration`，客户端以攻击快照还原本地起点。时间进度到达 1 时也不会自动淡出外边界，隐藏仍由权威触地 / 销毁状态决定。材质动画不增加逐帧 RPC。

新模型均为无碰撞表现。商店新增的牌签组件也不参与碰撞与导航。牌签采用屏幕空间控件，不会再从背面看到反字。

## 验证

- Development 与 DebugGame Editor 编译通过。
- 29 项定向检查通过：卡片渲染变换 / 回调、飘字运动、真实经验拾取与回池、回血数字、天坠触地与红圈持续、Boss 复用和十张地图配置。9 项无告警、20 项带隔离测试场景的预期告警，0 失败。
- 一项旧绕墙测试仍检查转向前的目标意图，本轮改为检查现有碰撞转向层，并使用建筑高度的障碍；没有为通过测试而修改游戏移动逻辑。
- 真实天坠攻击中，0.12 / 0.50 / 0.85 / 1.25 秒时红圈均显示，约 1.8 秒的触地后采样中已隐藏；触地逻辑没有改为计时爆炸。
- 白天樱庭、冰洲与黑夜森林、竹林、钟庭完成默认 1750 cm 镜头的自然战斗截图，共 10 张采样。采样时玩家均存活，场上实际可见敌人约 18–108 只；未关闭战斗或给自然截图开启无敌。
- 模型 / 商店 / 卡片的近景对照另使用临时布置与示例商品，专门检查视觉细节，不代表自然刷怪或实际购买。

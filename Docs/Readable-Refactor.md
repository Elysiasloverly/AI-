# 可读性重构与兼容边界

日期：2026-11-05。目标是减少重复维护点、明确职责，并让注释能够沿源码验证。

## 已整理的边界

| 原问题 | 当前入口 |
| --- | --- |
| 武器表、额外类数组、迫击炮补建、多个类型 switch | DT_WeaponConfig 负责配置，RogueWeaponCatalog 负责稳定身份，InitializeWeapons 负责生成 |
| TArray/原生数组两套加权抽取主体 | 一个只读范围模板；保留原权重、过滤和回退规则 |
| HUD 一个大文件混合设置/菜单/战斗反馈 | 调度、主菜单、战斗菜单、设置、战斗反馈、击杀反馈分文件 |
| Enemy 一个大文件混合生命周期/攻击/移动 | 基类调度与 LifeCycle、Combat、Movement；已有专用组件继续承担支持/绕障/表现 |
| 多类型远程参数重复直接赋值 | 共用直接时序拷贝；“0=原型基线”的覆盖参数仍单独处理 |
| 测试世界、控制器、地板和探针退出重复 | RogueTestWorld / RogueProbeSupport；场景条件和断言仍留在各测试 |
| 历史 UI 样式生成器混在当前工具中 | aiEditor/Private/UI/LegacyThemes；当前维护入口 Tools/UI/manage_ui.py 默认只验证 |

拆分 `.cpp` 不改变类名、父类或蓝图绑定，也不等于删除相同数量的代码。

## 移除的过时数据

正式 DA_GameBalance 的布局版本已核实为 1，项目蓝图对待删变量无图表读取。
已删除 55 个旧平铺标量及其 PostLoad 转换，移除停用的全场存活上限、计时切波、旧场地留白等字段。
角色不再维护 WeaponClasses、迫击炮补建类和废弃复活时长；武器/敌人不再保留中央音效之外的旧 AttackAudio 副本。
旧 BP_RogueArena 及其原生范围载体已归档移出；当前地图、RogueEnemySpawnRegion、RogueArenaBoundary 仍使用现有实现。

这次未移除各敌人类型限制、每波累计总量、护甲/永久进度字段，也没有修改存档节点 ID。
当前资产按新布局重存；导入更早的平铺版本资产，需要先用归档源码完成旧版迁移，不能直接期待本版自动转换。

旧迁移测试的二进制样本移到项目外备份；同一组公式边界改用显式当前字段构造，保留快照标签与输出，便于逐字比较。
测试不是简单删除：乱序批次、零/负上限、分母边界、缺失类型、个人卡池及各玩法回归仍保留。

## 注释约定

函数上方解释调用时机、数据来源、权威或生命周期约束；局部注释解释容易误改的原因。
避免只复述下一行、硬编码武器数量、宣称一次日志能证明全部联机正确，或保留已经失效的兼容路径说明。
注释区分“源码默认”“当前资产”“实测结果”；修改规则时同时更新对应文档和测试。

开发自检真实实现及采样状态由 WITH_DEV_AUTOMATION_TESTS 隔离；Shipping 只保留必要空接口。
aiEditor 仍是 Editor 模块，并保留非 Unity 编译，避免历史生成器的文件内同名辅助函数在合并编译时冲突。

# 武器配置指南

战斗数值统一在 `/Game/Data/Weapons/DT_WeaponConfig` 配置；模型与纯外观在对应弹体蓝图配置。改表后重新开始一局，运行中的武器使用开局读取的行副本。音效仍由 `DA_AudioConfig` 统一管理。

| DT 行 | 对应武器 | 主要战斗配置 |
|---|---|---|
| Projectile | 冰符·寒弹 | 伤害、冷却、数量、速度、连发、散射、弹体战斗 |
| Scythe | 银刃 | 轨道半径、旋转速度、刀片命中半径、同敌伤害间隔、转速/范围加成倍率 |
| Rocket | 冰焰·陨星 | 召唤高度、斜坠水平偏移、下坠速度、爆炸半径、半径升级、弹体战斗 |
| Laser | 星符·流光 | 折射次数、范围、伤害倍率、折射停止阈值 |
| HellTower | 焰符·灼光 | 基础伤害、每跳递增、跳间隔、最短跳间隔、最低起跳伤害 |
| Mortar | 冰符·霜玉 | 发射速度、爆炸半径、弹体战斗、迫击炮弹道 |
| Talisman | 灵符·归心 | 归心符战斗（出击/返回速度、命中范围、越过距离、超时、基础穿刺额度） |

| FrostBlade | 冰刀·霜月 | 永久解锁自动装备、扇形范围横斩、尺寸增伤、基础攻击系数、离身距离、穿透剑波 |

显示名以表内当前保存内容为准，稳定行 ID 不随武器改名变化。

## 新增分组

- **弹体战斗 → 命中与存活**：碰撞半径（厘米）和存活时间（秒），适用于寒弹、火球、迫击炮；当前存活时间沿用 30 秒。
- **迫击炮 → 迫击炮弹道**：弧度、重力倍率、最低水平速度、最短/最长飞行时间。
- **灵符·归心 → 归心符战斗**：出击速度、返回速度（厘米/秒）、穿刺后的越过距离、扫掠半径、两类超时、基础穿刺敌人数、基础每敌穿刺次数。卡片加成叠加在基础额度上。
- **公式 → 弹速加成倍率**：沿用原逻辑，普通弹体 1、火球 0.75、迫击炮 0.5。

刀片的环绕半径与转速会改变实际接触伤害，归于 DT；灵符的待命环绕只负责展示，不造成接触伤害，半径、高度、角速度仍在蓝图。

## 蓝图外观

对应蓝图位于 `/Game/BP/Projectiles/`。模型、组件缩放、材质、光晕、拖尾、朝向修正以及 **外观 → 开火特效 → 开火闪光与碎光** 均在蓝图内设置。激光和焰柱使用各自独立的光束蓝图。光束的显示时长、持续刷新间隔和寿命补偿在光束蓝图的“外观 → 光束节拍”设置，不影响伤害跳间隔。纯外观的尺寸不会自动改变命中范围；刀片巨化卡仍会同步放大模型与 DT 定义的伤害碰撞范围。

旧蓝图战斗字段和旧表开火闪光字段只保留加载兼容，细节面板不再显示，运行时不会将其当作配置来源。每次出池都会重新应用 DT 参数；客户端的零伤害表现也使用同一行配置。服务器负责伤害结算。

## 同类武器的目标分配

同一玩家的同一种武器优先攻击尚未被本武器分配的敌人；候选目标都已有分配时，优先选择分配次数少的目标，同负载沿用原有远近优先顺序。各玩家、不同武器分别管理，仍可共同攻击同一个 Boss。

寒弹、火球、迫击炮会记录在途弹体的目标，命中、超时或回池后释放。灵符在穿刺期间保留当前目标，返航时释放；重复穿刺卡仍按实际次数完成。激光的主光束和折射段共享本轮分配，折射优先覆盖其他主光束之外的敌人。焰柱在目标不足时允许多柱集火，并保留连续锁定的递增伤害；出现新敌人后拆开重复锁定。环绕刀片按接触范围造成伤害，不分配锁定目标。

这是索敌优先级，弹体仍可碰到路上的其他敌人，爆炸也保留范围伤害。敌人死亡、回池重生或弹体销毁后，旧目标记录不会继承到新出生周期。

## 冰刀·霜月

扇形范围横斩单刀使用 `FrostBlade` 行；升级树永久解锁后每局自动装备，不需要选卡获取。正常模式下服务器根据各玩家自己的解锁进度给予 1 把，编辑器的“按武器表初始数量”开关仍可用于调试；不会因为数量加成变成多把刀。默认剑波宽 480 厘米、命中半宽 240 厘米、寿命 30 秒。四种专属卡和全部配置入口见 [Frost-Moon-Blade.md](Frost-Moon-Blade.md)。

## 冰焰·陨星（原火丸）

在 `DT_WeaponConfig → Rocket → 冰焰·陨星` 设置天降弹道：相对目标的召唤高度 1100 cm、斜坠水平偏移 650 cm、下坠速度 1900 cm/s。水平偏移越大，轨迹越倾斜。弹道围绕玩家朝向目标的水平向量生成，目标恰好位于玩家处时使用玩家朝向。随机偏转只改变召唤方位，仍指向选中目标，不会随机把球打向天空。

`BP_RogueRocketProjectile` 保留模型朝向和基础缩放，使用独立的冷白核心、蓝色冰焰材质。冰焰扩散沿用每张 +90 cm；飞行球体与焰尾尺寸 = 蓝图基础尺寸 × 实际爆炸半径 / DT 基础爆炸半径。基础半径为 280 cm 时，一张卡是约 1.321 倍，两张约 1.643 倍。通用攻击范围影响爆炸半径时也反映到外观。碰撞根不随外观缩放，伤害范围按爆炸半径结算。

模型出池激活前和回池时恢复原始尺寸，避免不同玩家或前后两发串用升级。服务器广播本次召唤起点、方向、速度、爆炸半径和外观倍率，客户端播放零伤害副本。内部行名 `Rocket`、升级枚举、节点 ID 和费用不变，现有解锁存档继续使用。

外观材质：`/Game/GameAssets/ArtDirection/IceMeteor/Materials`。起势与爆炸：`BP_CastIceMeteor`、`BP_BlastIceMeteor`（位于 `/Game/BP/Effects/WeaponCast`）。落地蓝焰会减速并持续造成范围伤害，没有冻结。

2026-11-06：武器表的旧编辑器分类已改为当前展示名（冰符·寒弹、冰焰·陨星、银刃、冰符·霜玉、焰符·灼光、星符·流光），共用项为“光束共用”。仅调整分类、提示和显示标签，原字段标识、行名及表内数值保留。

# 统一音频系统

唯一配置入口：`/Game/Data/Audio/DA_AudioConfig`。背景音乐、武器攻击音效、敌人攻击音效和按钮音效都放在这里。音量偏好另外保存在本机 GameUserSettings.ini，不写回资产，也不复制给队友。

## 背景音乐

“曲目”提供主菜单与房间背景音乐、白天战斗、黑夜战斗、Boss 战斗、游戏结束五个槽。支持 SoundWave、SoundCue、MetaSound Source。每首可设音量和是否循环；“切换”中统一配置交叉渐变时间，默认 1 秒。结算默认不循环，未配置的曲目保持安静；已有曲目保留用户配置。

音乐按本机收到的 GameState 切换：游戏结束优先于 Boss，Boss 优先于昼夜。Boss 结束恢复当前阶段；30 秒休整继续白天曲目，进入黑夜阶段后换曲。多个 Boss 同时存在不会重复重播。

管理器归属 GameInstance，两个 2D 音频组件跨关卡保留并交叉渐变。同一曲目被相邻场景重复请求时继续播放。游戏暂停时音乐继续；音乐音量为零时暂停音乐组件，调回后继续。

单次 SoundWave 播完可续播；要求无缝循环时建议在 SoundCue 或 MetaSound 内制作接点。管理器不改写素材的循环属性。

主菜单音乐直接配置在 `DA_AudioConfig → 曲目 → 主菜单与房间背景音乐 → 音乐`。该插槽在主菜单、房间及菜单内的设置/升级树页面共用。填入自己的 SoundWave、SoundCue 或 MetaSound Source 后生效；循环及曲目音量在同一处设置。已有音乐配置保留，留空时安静。

## 按钮音效

`DA_AudioConfig → 界面音效 → 按钮交互` 统一配置悬停声、按下声、各自音量及启用开关。按钮按下时先播放确认声，再由原有点击逻辑处理导航或玩法；禁用按钮不会触发正常输入声。

覆盖主菜单、多人菜单/房间行、设置、教程、暂停、结算、选卡、商店及升级树。动态创建的卡片、升级节点和房间行在自己的构造入口接入。重复打开或绑定不会重复叠声。只清除按钮样式中的旧内建声音，保留配色、圆角、边框和原有业务事件。

音频管理器使用本机2D播放、SC_UI分类、最多6声并发；跟随设置里的“音效音量”，游戏暂停时也能播放。每次移入按钮播放一次，停留不重复，移出再移入或快速切到其他按钮都会再次播放；没有跨按钮的时间节流。短确认声可以跨地图播完，不因开始游戏或返回菜单被截断。新建自定义WBP时，可在构造后调用 `Bind Widget Button Sounds`；若运行时再添加按钮，添加后再调用一次即可。

## 武器音效

展开“武器音效 → 各武器攻击音效”，包含冰符·寒弹、银刃、冰焰·陨星、星符·流光、焰符·灼光、冰符·霜玉六项。按武器类识别，子类优先，不依赖中文显示名称。新增武器可新增条目。

一次攻击随机播放一个非空变体，空槽跳过；有多个不同素材时避免立即重复。每项提供三个变体槽，可增加；当前冰符·寒弹、冰焰·陨星、星符·流光、焰符·灼光、冰符·霜玉各有三个攻击变体；银刃按要求留空静音，旧音效资产已删除。支持音量、音高随机范围、最小播放间隔、距离衰减、并发配置。

- 散射一轮响一次；冰符·寒弹连发的每轮分别播放。
- 激光折射不重复叠放；焰符·灼光同一次多目标刷新最多响一次，默认最小间隔 0.25 秒。
- 银刃声音槽当前留空，不播放音效；未来重新配置时，仍按一次完整环绕触发，不按每帧或每次伤害触发。
- 客户端根据服务器确认事件播放，避免自己预测与确认重复响。

DT_WeaponConfig 继续负责玩法数据。旧攻击音效字段只保留迁移读取能力，已隐藏，运行时不读取它。

## 敌人音效

展开“敌人音效 → 各敌人攻击音效”，包含原生默认项和 14 个现有敌人蓝图类。

只需在“所有敌人默认（原生基类）”或 BP_EnemyBase 条目配置一次。具体敌人全部留空时按类继承向上寻找；填入音效覆盖父类。明确关闭“启用攻击音效”会静音该类，不再回退。

旧敌人蓝图攻击音效字段已隐藏，不再是运行时配置来源。受击材质等原有配置保持不变。

成功近战命中、远程齐射和环形弹幕各发送一次攻击事件。对象池重新激活重置播放间隔，上一轮生命周期迟到的声音事件会被丢弃。

## 设置菜单

WBP_SettingsMenu 中音效音量和背景音乐音量相邻显示，每次调整 10%，0% 静音。音量即时生效并保存；画面修改仍需点击应用。主菜单和战斗内共用这份面板。

旧 MasterVolume 在没有新键值时迁移为两路初始音量。此后 SoundEffectsVolume、MusicVolume 分别保存，切图、重建 HUD、重新启动均读取各自值。

混音分类位于 `/Game/Audio/Classes`：SC_Master 下的 SC_Music、SC_SFX、SC_UI。SM_UserVolumes 承载运行时混音覆盖。Music 受背景音乐音量控制，SFX 和 UI 受音效音量控制。普通未指定分类的声音默认归 SC_SFX；新界面音效建议归 SC_UI。

攻击声在播放前指定 SC_SFX，按钮声指定 SC_UI，背景音乐指定 SC_Music，不需要逐个修改音频文件分类。

## 代码职责

- RogueAudioConfig：唯一编辑数据源，按类匹配和父类回退。
- RogueMusicSubsystem：音乐状态、两个持久组件、本机音量与保存、统一按钮反馈。
- RogueCombatAudioSubsystem：空间音效、变体、节流、距离衰减和并发。
- 武器与敌人：只通知实际攻击，不读取菜单音量、选择曲目或维护音频资产。

各客户端本地播放音乐；专用服务器不创建音乐组件。不复制音乐资源或额外的音乐播放 RPC，状态依据现有 GameState。

攻击排查可执行 Rogue.Audio.Debug 1，结束后用 Rogue.Audio.Debug 0 关闭。带 AudioProbe 的回归命令仅供临时测试，正常游戏无需启用。

仅更新 Development Editor 配置。测试覆盖中央配置、继承、攻击播放节奏、音量保存、实际播放组件、跨图和菜单按钮；静音测试声音仅在内存中创建，不保存进项目。实际曲目的响度与听感在填入音频后调整。

# DA_GameBalance 调参说明

在内容浏览器打开 `Data/Core/DA_GameBalance`。详情面板按下面九组排列；字段悬停说明会解释公式、单位和特殊值。

| 分组 | 主要修改什么 |
|---|---|
| 00.成长曲线 | CurveTable统一调普通/Boss属性、每波总数与刷怪间隔；缺行回退下方公式 |
| 01.敌人种类 | 哪些类型从第几波进入刷怪池，以及各类型的生命、速度、伤害修正 |
| 02.刷怪数量与速度 | 每波累计总量、一次尝试刷几只、刷怪间隔、生成半径和地面射线 |
| 03.普通敌人属性 | 生命／速度／伤害的基础与每波成长，以及额外生命强化阶段 |
| 04.首领属性 | 首领基础成长、刷新节奏、分界波前后强化与通用速度倍率 |
| 05.击杀奖励 | 普通敌人与首领分别掉多少经验、给多少金币；首领冰砖也在这里 |
| 06.商店 | 卡牌数量、卡牌基础价格、刷新基础价格和自动刷新间隔 |
| 07.运行时 | 对象池预热、性能阈值与场景优化 |
| 08.昼夜阶段 | 白天结束波次、休整倒计时、昼夜清场推进、休整倒计时、黑夜数量倍率与生成速度倍率 |

## 常见调整

- 想增加一波的普通怪总量：优先调曲线表的 `EnemiesPerWave`；未配置该行时才调“第1波普通怪总数”“每波增加的普通怪总数”和“每波普通怪总数封顶”；特定类型仍在敌人表配置 `MaxAlive` 与 `MaxSpawnPerWave`。
- 想让怪刷得更快：优先调曲线表的 `SpawnInterval`，仍受最短间隔约束；未配置该行时才调“每波刷怪加速增量”“刷怪加速上限”“最短刷怪间隔”和“基础刷怪间隔”，都在 `02.刷怪数量与速度`。
- 想一次多刷几只：展开“每次刷怪数量规则”。每项只需填开始波次和每次目标只数。多项同时满足时，列表里最后一项生效。
- 想提高后期坦度：优先调曲线表的 `EnemyHealth`；未配置该行时才在“额外生命成长阶段”里调整开始波、每波增加比例和累计加成上限。多个已经开始的阶段会同时生效并依次相乘。
- 想让首领后期更强：优先调曲线表的 `BossHealth` / `BossDamage`；未配置对应行时才调整“后期强化从第几波开始”及两段生命／伤害倍率。到达分界波后使用后期段，前后两段不会叠乘。
- 想改经济节奏：分别调“击杀奖励”和“商店”。卡牌按类型的已购次数涨价，手动刷新价格也会逐次翻倍，所以商店中配置的是基础价格。

## 合并后的配置含义

原来的双只／三只刷怪字段合并成一个规则列表。这里的“2／3”是一次刷怪尝试的目标只数，不是把刷怪速度乘2／乘3；场上数量、敌人类型限制和落点仍会影响实际刷出数量。清空列表后每次尝试刷1只。

原来的中期／后期生命强化合并成一个阶段列表。“每波增加比例”填 `0.08` 表示增加8%；“加成上限”填 `0.72` 表示本阶段最多增加72%，即生命乘1.72。开始波当波就增加一次；上限为0或负数表示该阶段不封顶。清空列表可以关闭额外阶段强化。

生命、速度、伤害统一使用“基础值＋每波增加”的小组。普通敌人在第1波使用基础值，此后每波增加一次。首领沿用原算法：基础值加上当前波次乘每波增加，因此第1波也计算一次成长。

普通敌人的经验和金币共用“基础奖励／每几波增加1点／基础奖励上限”的结构，数值分别保存。普通经验在基础奖励封顶后，还会加上敌人类型的额外经验；首领没有这项额外经验。

经验在敌人出生时按当时波次确定，金币在击杀时按当前波次计算。两类奖励分别设置，以保留各自的计算规则。

## 容易看错的地方

- “刷出倾向（权重）”是相对概率。同类型在不同波次的多条记录会累计权重，不能直接当作重复行删除。波次池留空时使用项目内置规则。
- 已取消全场存活上限、随波增长上限和 Boss 全场名额调整；旧值仅供旧资产反序列化，不显示、不参与计算。批量规则不再检查全场空余名额。
- 刷怪加速只改变间隔，不增强敌人的生命或伤害。
- “最终生命上限”只影响普通敌人；负数表示不限，0表示零生命档案，不表示关闭限制。
- 商店卡牌数量是目标数量，可用升级类型较少时实际数量会减少。

旧版资产的55个标量参数会按版本自动迁移到新分组，保留原值。旧字段作为隐藏的迁移输入保留；正常编辑和运行使用新分组。保存新版本后，再次加载不会用旧字段覆盖已编辑的分组或已清空的规则列表。

## 清场切波（2026-10-24）

每波累计名额保留，全场同时存活限制已移除。`BaseEnemiesPerWave`、`EnemiesPerWaveIncrement`、`EnemiesPerWaveLimit` 控制本波一共生成多少普通怪；Boss 额外生成。达到名额后不会继续补刷；白天清完场上全部敌人切波，黑夜也清场切波。`DT_EnemyArchetypes` 中各类型的同时存活上限与每波上限仍然有效。每类名额全部用完时以可用名额为准结束本波生成，避免白天等待永远刷不出的数量。

旧 `WaveDuration` 不再生效；`RunTimeSeconds` 仅记录真实战斗时间，不再用来推算波数。三次切图都先停刷、清场，再倒计时 30 秒；默认边界为 35、50、85。

## 黑夜清场推进（2026-10-30）

昼夜现在统一为清场切波：完成当前波次生成名额，击败全部敌人和Boss后，生成下一波。第50波结束后按原规则进入清场休整和30秒切图倒计时；第99波清场后进入100波胜利。黑夜普通怪数量与生成速度2倍保留，攻击速度为正常值。旧“黑夜波次时长”已隐藏，仅供旧资产反序列化，不再参与调度。

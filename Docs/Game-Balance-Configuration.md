# DA_GameBalance 调参说明

在内容浏览器打开 `Data/Core/DA_GameBalance`。详情面板按下面六组排列；字段悬停说明会解释公式、单位和特殊值。

| 分组 | 主要修改什么 |
|---|---|
| 01.敌人种类 | 哪些类型从第几波进入刷怪池，以及各类型的生命、速度、伤害修正 |
| 02.刷怪数量与速度 | 场上能同时存在多少只、一次尝试刷几只、刷怪间隔多快 |
| 03.普通敌人属性 | 生命／速度／伤害的基础与每波成长，以及额外生命强化阶段 |
| 04.首领属性 | 首领基础成长，分界波之前与之后的强化，以及通用速度倍率 |
| 05.击杀奖励 | 普通敌人与首领分别掉多少经验、给多少金币 |
| 06.商店 | 卡牌数量、卡牌基础价格、刷新基础价格和自动刷新间隔 |

## 常见调整

- 想增加同屏怪物：调“每波增加的场上名额”和“场上名额总上限”。生成系统的基础名额仍在 GameMode 的 `Spawn Settings` 中。
- 想让怪刷得更快：调“每波刷怪加速增量”“刷怪加速上限”和“最短刷怪间隔”。基础刷怪间隔同样来自 GameMode 的 `Spawn Settings`。
- 想一次多刷几只：展开“每次刷怪数量规则”。每项只需填开始波次、至少空余名额、每次目标只数。多项同时满足时，列表里最后一项生效。
- 想提高后期坦度：在“额外生命成长阶段”里调整开始波、每波增加比例和累计加成上限。多个已经开始的阶段会同时生效并依次相乘。
- 想让首领后期更强：调整“后期强化从第几波开始”及两段生命／伤害倍率。到达分界波后使用后期段，前后两段不会叠乘。
- 想改经济节奏：分别调“击杀奖励”和“商店”。卡牌按类型的已购次数涨价，手动刷新价格也会逐次翻倍，所以商店中配置的是基础价格。

## 合并后的配置含义

原来的双只／三只刷怪字段合并成一个规则列表。这里的“2／3”是一次刷怪尝试的目标只数，不是把刷怪速度乘2／乘3；场上数量、敌人类型限制和落点仍会影响实际刷出数量。清空列表后每次尝试刷1只。

原来的中期／后期生命强化合并成一个阶段列表。“每波增加比例”填 `0.08` 表示增加8%；“加成上限”填 `0.72` 表示本阶段最多增加72%，即生命乘1.72。开始波当波就增加一次；上限为0或负数表示该阶段不封顶。清空列表可以关闭额外阶段强化。

生命、速度、伤害统一使用“基础值＋每波增加”的小组。普通敌人在第1波使用基础值，此后每波增加一次。首领沿用原算法：基础值加上当前波次乘每波增加，因此第1波也计算一次成长。

普通敌人的经验和金币共用“基础奖励／每几波增加1点／基础奖励上限”的结构，数值分别保存。普通经验在基础奖励封顶后，还会加上敌人类型的额外经验；首领没有这项额外经验。

经验在敌人出生时按当时波次确定，金币在击杀时按当前波次计算。两类奖励分别设置，以保留各自的计算规则。

## 容易看错的地方

- “刷出倾向（权重）”是相对概率。同类型在不同波次的多条记录会累计权重，不能直接当作重复行删除。波次池留空时使用项目内置规则。
- “Boss在场时的上限最低值”调整的是场上数量上限，不是保证至少生成这么多只敌人。它可能把较低的“场上名额总上限”重新抬高。
- 刷怪加速只改变间隔，不增强敌人的生命或伤害。
- “最终生命上限”只影响普通敌人；负数表示不限，0表示零生命档案，不表示关闭限制。
- 商店卡牌数量是目标数量，可用升级类型较少时实际数量会减少。

旧版资产的55个标量参数会按版本自动迁移到新分组，保留原值。旧字段作为隐藏的迁移输入保留；正常编辑和运行使用新分组。保存新版本后，再次加载不会用旧字段覆盖已编辑的分组或已清空的规则列表。

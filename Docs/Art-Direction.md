## 角色突出：第一步（2026-11-03）

默认镜头距离由 2100 cm 调整为 1750 cm。角色在屏幕上的线性尺寸预计增加约 20%；相应地，默认可见场地范围收窄。滚轮缩放仍可在原来的 700–3600 cm 范围内调整。镜头俯仰角、FOV、角色模型和战斗判定保持原值。

编辑入口是 `BP_RogueCharacter` 的 `SpringArm` 组件，参数 `Target Arm Length`。缩放上下限在同一蓝图的类默认值 `Camera` 分类中。

玩家模型与扫帚的材质槽使用 `/Game/GameAssets/ArtDirection/PlayerFocus` 中的独立版本，保留原贴图和原材质逻辑，并在原自发光基础上加入少量暗部补光与柔和冷色边缘光。原始素材保留，敌人材质没有跟随更换。材质仍由玩家蓝图的组件槽控制，没有运行时硬编码覆盖。

这些材质里的可编辑参数：

| 参数 | 当前值 | 作用 |
|---|---:|---|
| `PlayerShadowFill` | 0.07 | 暗处保留一点模型原色 |
| `PlayerRimStrength` | 0.18 | 视角相关的柔和边缘补光 |
| `PlayerRimTint` | (0.35, 0.65, 0.85) | 偏冷的边缘颜色 |

这层补光直接写在表面材质里，不新增描边网格、灯光组件或逐帧更新。角色缩放、碰撞胶囊、武器索敌范围与数值表没有随镜头变化。

另外，按玩家需求新增了一层朦胧白色描边：`PlayerFocus/MI_PlayerSoftWhiteOutline`，母材质 `M_PlayerSoftOutline`。它配置在玩家模型与扫帚组件的 `Rendering → Advanced → Overlay Material`，没有替换原材质槽。要关闭时清空这两个组件的覆盖材质即可。

| 描边实例参数 | 默认值 | 用途 |
|---|---:|---|
| `OutlineWidthCM` | 4.5 | 可见轮廓的世界空间扩张宽度，单位厘米 |
| `OutlineOpacity` | 0.28 | 白色轮廓透明度 |
| `OutlineSoftness` | 0.85 | 轮廓随视角衰减的柔和程度 |
| `OutlineGlow` | 1.8 | 白色光强 |
| `OutlineColor` | 白色 | 可修改轮廓颜色 |
| `InnerSoftGlow` | 0.025 | 内缘的少量柔光，避免覆盖角色原色 |

扫帚使用同一母材质的较弱实例 `MI_PlayerAccessorySoftWhiteOutline`：宽度 1.5 cm、透明度 0.16、光强 1.3。这样细密的扫帚枝条不会整片泛白。

描边保留深度检测，墙体会正常遮挡；只扩张渲染外壳，不扩大碰撞。玩家组件开启 `Disallow Nanite` 以支持 UE 5.5 的覆盖材质显示，共享的角色和扫帚网格资产仍保留 Nanite 设置，敌人组件不受影响。覆盖材质会增加玩家模型的绘制开销；当前没有给所有敌人开启这层描边。两个玩家组件的渲染包围盒有少量留边，避免外壳在边缘被裁掉。

本次先检查樱庭白天、竹林月夜、红魔钟庭月夜三种环境。正式游玩截图使用保存后的默认镜头；固定场景的前后对照会临时停下战斗，已有拖尾消散后再拍摄，避免把特效结束误认为角色材质的改善。

## 场景层次

地面使用低对比绘本底纹，让角色、弹幕和红色预警先被看见。建筑保留朱红、靛蓝和旧金色，树叶与石材使用较大的色块。接触阴影只负责把角色、石块和地面接起来。

| 场景 | 环境点缀 | 配色侧重 |
|---|---|---|
| 森林 | 暖色萤光、薄雾 | 苔绿、木色、灯笼橙 |
| 樱庭神社 | 樱色花瓣 | 浅石、朱红、樱粉 |
| 雾湖冰洲 | 冰晶碎光 | 冰蓝、深湖蓝、少量暖灯 |
| 竹林月径 | 竹叶 | 青绿、冷月蓝、灯笼暖色 |
| 红魔钟庭 | 红金微光 | 酒红、旧金、蓝灰石 |

白天使用暖主光和冷色环境补光，夜晚使用较弱的蓝色月光与橙色局部灯光。雾与微粒保持低密度。地面装饰符阵没有碰撞，也不是技能范围提示。

## 编辑器里怎么改

新资源统一放在 `/Game/GameAssets/ArtDirection`：

| 位置 | 用途与常用参数 |
|---|---|
| `Source` | 自制贴图的 PNG 源文件与生成提示记录 |
| `Textures/T_PaintedStone` | 绘本石材底纹 |
| `Textures/T_OfudaHit` | 透明符纸星芒，用于施法与命中 |
| `Textures/T_ShrineSeal` | 透明符阵，用于扩散光环与地面装饰 |
| `Materials/M_PaintedSurface` | 场景表面母材质；颜色、底纹强度、粗糙度、金属度 |
| `Materials/MI_Paint_*` | 各种石材、屋顶、木材、树叶的可编辑材质实例 |
| `Materials/M_ForestGround_Painted` | 保留原森林分层地形，收敛鲜绿和细节饱和度 |
| `Materials/M_PaintedWater` | 低对比缓慢流动水面 |
| `Materials/M_PaintedSky` | 昼夜天空渐变，配有两个实例 |
| `Materials/M_OfudaCombatAccent` | 通用闪光与旧预设材质；玩家独立施法和命中使用后续文档中的材质 |
| `Materials/MI_Motes_*` | 各场景昼夜微粒的颜色、形状、透明度和漂移速度 |
| `Materials/MI_Mist_*` | 各场景昼夜薄雾的颜色与透明度 |
| `Materials/MI_Seal_*` | 各场景地面装饰符阵 |

在 `/Game/Map/Day` 或 `/Game/Map/Night` 打开地图，大纲的 `Atmosphere/ArtDirection` 内可以找到环境点缀：

- `Art_*_Petals` / `Art_*_Motes`：`BP_ArtAmbience` 实例。调整微粒数量、分布半径、最小/最大尺寸、最远显示距离、随机种子，再点“重新分布微粒”。在 `Motes` 组件的材质槽选择对应实例。
- `Art_EdgeMist_*`：三片低透明度薄雾，可移动、缩放或隐藏。
- `Art_ShrineSeal`：出生区域的淡符阵，可移动、改材质或隐藏。

通用环境蓝图位于 `/Game/BP/Effects/BP_ArtAmbience`，父类是 `ARogueArtAmbience`。地图中的参数是实例覆盖值，改蓝图默认值不会覆盖地图里已有的实例值。

光照在各地图的 `Lighting` 目录：主光控制日光/月光，SkyLight 控制环境补光，PointLight 控制灯笼等局部暖光。曝光、泛光、暗角和接触阴影在 PostProcessVolume 的设置里。改光照后应在玩家视角确认角色、绿线治疗和红圈预警的辨识度。

## 战斗特效与性能约束

通用 `BP_CombatAccent` 使用 `M_OfudaCombatAccent`；玩家独立施法、爆炸与武器命中使用上述后续精修文档中的蓝图和材质。已有对象池继续处理闪光、扩散光环和碎片；颜色、时长、尺寸和触发间隔仍在原武器/敌人外观配置里。

环境微粒使用一个实例化网格组件，材质的 Time/WPO 提供动画。每个微粒不是单独的 Actor，不使用逐帧逻辑，不发网络 RPC，不产生碰撞、阴影或导航障碍。距离较远时淡出。专用服务器清空实例。

场景调整保留原始 FBX 顶点、模型尺寸和碰撞代理；原纹理材质仍保留。商店、出生点、刷怪区域、空气墙的变换保持原值。十张战斗图继续使用 `BP_RogueGameMode`，不能为了重做美术改回原生 GameMode，否则敌人蓝图映射可能丢失。

## 贴图来源

石材、命中星芒和符阵由本次内置生图工具制作，原图保留在 `Source`。完整提示词记录在 `Source/Generated-Art-Prompts.json`。微粒、水面、天空和低透明度雾使用项目内的材质节点制作。

后续添加特效时，先在真实战斗视角确认尺寸和透明度，再增加细节。大型高亮圆圈留给技能或敌人预警；装饰不应与它们使用相同的颜色、亮度和边缘。

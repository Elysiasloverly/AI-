# 鸦天狗：天坠弹与触地散华

更新：2026-10-30。

## 攻击流程

1. 施法时锁定存活玩家当前位置，从玩家脚边向下检测静态地面，生成红圈；之后玩家移动不拖动落点。
2. 大型弹体在落点上空召唤，朝施法者方向偏移260厘米；悬停0.8秒后向落点斜向砸下，下落约0.9秒。
3. 红圈在悬停和整个下落阶段持续显示，服务端球形扫掠确认触地后才隐藏。客户端不能仅靠本机倒计时撤掉预警。
4. 触地时，红圈半径内的存活玩家受一次落地伤害，同时生成24发沿水平方向向外扩散的普通子弹。
5. 敌人死亡、归池或重新出池、游戏结束会取消尚未触地的攻击，并清除红圈；切图随原世界清理。单次攻击最长30秒，地面被移走时不会按动画时间凭空爆发。

普通散弹继续使用该行顶层 `ProjectileClass`：`BP_EnemyProjectile_Marksman`。人魂现在使用自己文件夹里的独立 `BP_EnemyProjectile_Orbiter`；鸦天狗的大型落弹与普通散弹分别维护。

旧的普通单发“弹丸速度/伤害倍率/枪口特效”只在切回单发等模式时消费；天坠弹使用独立块内的落地与环形弹幕参数。Boss同样使用天坠弹，BossOverride冷却当前4.2秒；黑夜攻速倍率缩短攻击周期，不压缩红圈悬停和下落时间。

## 蓝图中调整外观

`/Game/BP/Enemy/Marksman/BP_EnemySkyfall_Marksman`：

- `SkyfallCore`：替换大型弹体模型、材质和缩放，C++不会覆盖这些配置。
- `GroundWarning`：红圈贴花材质、投影样式；保留 `Rogue.SkyfallWarning` 组件标签。半径由数据表驱动，位置锁在地面。
- `OnSkyfallImpact`：可追加触地粒子或动画。不要在这个事件再次结算伤害或生成普通子弹。

材质：`/Game/GameAssets/Enemies/Utility/M_EnemySkyfallCore` 与 `MI_EnemySkyfallWarning`。

红圈使用贴花，地面需要接收贴花。默认投影深度400厘米，适应场景地面的小幅高差；地面高度检测与触地扫掠查询WorldStatic。无静态地面的地方不开始攻击。

## 联机与回收

大型弹体是独立复制Actor。起点、锁定落点、服务器时间和参数统一复制；服务端独立检测实际碰撞并结算伤害，客户端重建轨迹。触地状态与实际撞击点一起复制，客户端收到后隐藏红圈并生成零伤害的普通弹幕表现。普通子弹仍走现有对象池，穿过友方敌人、命中玩家或墙体后回收。

调用链：`GAS远程攻击 → ARogueEnemy::StartSkyfallAttack → ARogueEnemySkyfallProjectile → 真实地面扫掠 → 范围伤害 + 普通子弹对象池`。

# 开火与受击碎光

开火时增加短星芒、扩散光环和少量飞散碎光；敌人真实掉血时，在原有闪白之外增加淡金命中火花。效果不带碰撞、灯光、相机震动或额外伤害。

## 在哪里调整

- 武器：`/Game/Data/Weapons/DT_WeaponConfig` → 对应行 → **开火特效 / 开火闪光与碎光**。
- 敌人：`/Game/BP/Enemy/Common/BP_EnemyBase` → 类默认值 → **敌人 / 受击反馈 / 受击火花与碎光**。在基类设置一次即可继承；子蓝图可单独覆盖。
- 效果蓝图：`/Game/BP/Effects/BP_CombatAccent`，父类 `RogueCombatAccentEffect`。
- 发光材质：`/Game/GameAssets/Combat/Accents/M_CombatAccent`。颜色、透明度、形状参数分别为 `Tint`、`Opacity`、`Shape`，由效果实例驱动。

每份设置可调整启用、特效蓝图、颜色、大小倍率、持续时间、最短触发间隔、碎光数量和是否显示扩散光环。原生实现最多显示 6 片碎光；关闭特效只影响画面。

| 武器 | 发射配色 |
|---|---|
| 冰符·寒弹 | 冰蓝短闪与晶屑 |
| 银刃 | 淡蓝旋转节拍光环，每转一圈一次 |
| 焰符·火丸 | 橙红闪光与火星 |
| 星符·流光 | 蓝紫光束起点闪光 |
| 焰符·灼光 | 金橙短闪，持续照射时限制重复频率 |
| 冰符·霜玉 | 较宽的冰蓝施法涟漪 |
| 灵符·归心 | 朱红施法涟漪 |

敌人受击默认持续 0.18 秒、最短间隔 0.09 秒，6 片淡金碎光，不显示大光环。材质闪白仍由原来的受击闪白组件控制，两种效果分别开关。若敌人蓝图重写“敌人受击”事件，需要调用父类才能保留这两种默认表现。

## 联机与性能

开火闪光共用既有的服务器确认表现批次，每轮只标记一条；本机预测不额外播放。音效和闪光各有独立标记与设置，静音或缺少音频素材时仍有视觉反馈。银刃的连续环绕节拍在各端本地生成。

敌人火花复用既有的受击复制快照，多次密集伤害可能合并成一次火花；实际伤害仍逐次结算。初始化和回血不触发。对象池新生命会重置特效触发间隔，过期受击不会补播。

效果对象不复制，各端在当前 World 的战斗对象池中复用。默认最多同时显示 48 个，密集敌群降为 16 个，池最多保留 64 个；摄像机 5000 厘米外跳过。结束后隐藏并停止 Tick，动态材质复用，不参与寻路。

蓝图需要从其他事件播放同一效果时，可调用当前 World 的 `RogueCombatPoolSubsystem.PlayCombatAccent`，传入设置、位置、方向和是否命中。

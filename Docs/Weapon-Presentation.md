# 武器与升级卡命名

2026-10-28 按当前蓝图表现与攻击实现统一名称。NodeId、升级枚举值、武器类与资产路径保持原标识，保留已有存档和引用。

| 原名称 | 当前名称 | 对应表现 |
|---|---|---|
| 御札 | 冰符·寒弹 | 冰蓝灵弹自动直射；当前蓝图主体是球体，因此不称冰锥或霜针 |
| 银刃 | 银刃 | 冰月牙刀刃环绕角色切割，沿用原称呼 |
| 八卦炉 | 焰符·火丸 | 发射橙红火球，命中爆炸 |
| 极限火花 | 星符·流光 | 蓝白激光，专属升级可以折射 |
| 御柱 | 焰符·灼光 | 金橙火焰光束持续锁定，伤害逐跳提高 |
| 阴阳玉 | 冰符·霜玉 | 抛物线冰球，落地爆炸 |
| 新增灵符 | 灵符·归心 | 灵符环绕待命，飞出穿刺敌人后返回 |

数量升级统一使用寒弹增殖、银刃环阵、火丸齐射、流光齐射、灼光分流、霜玉连投。特殊升级使用冰符连诵、火丸扩散、焰心递燃、星尘折射、霜玉扩散、银刃巨化和红雾吸血。

一般属性卡中，赛钱箱改为引灵之印，蓬莱之药改为长命祈愿，隙间跳跃改为隙间步法，弹幕偏转改为弹幕护身，月之药改为月露回生，流星弹改为流星加护，使标题更接近实际效果。

冰与火描述外观。本次没有加入冻结、减速或持续灼烧机制。

升级和商店共用 DT_UpgradeDefinitions；永久许可在 DA_UpgradeTree。介绍按当前数据行的 Magnitude / FirstMagnitude 生成，避免将霜玉扩散 +100 cm 与火丸扩散 +90 cm 混写。

星尘折射的当前实现先按 RefractionDamageScale 计算折射伤害，后续折射段沿用该伤害，不是每跳再次乘这个倍率。介绍不再承诺每跳减半。

Tools/Presentation/catalog.json 保存统一命名和武器说明；Tools/Presentation/update_assets.py 默认只刷新文案，不重建 UI、不重置存档或前置关系。需要修改词句时同步 C++ 默认配置及游戏指南。旧的 Tools/rename_content_to_touhou.py 现在转入此入口，避免旧脚本恢复过期名称。

此轮资产重载与修改前副本比较：武器参数、升级数值和上限、节点 ID / 费用 / 前置 / 等级、攻击音效与音乐、地图原有几何及玩法 Actor 均一致。

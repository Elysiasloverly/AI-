# 森林昼夜氛围

2026-10-28 第二版：地图仍为 /Game/Map/Battle_Day 与 /Game/Map/Battle_Night。重点是林间明暗、低空流雾、萤火和战斗视野。

## 编辑入口

- 大纲“氛围/午后”“氛围/月夜”：太阳/月光、天光、后处理、灯笼和微光。
- 子目录“贴地流雾”：5 片没有碰撞的材质雾。按需要移动、缩放、隐藏；不是障碍物。
- /Game/GameAssets/Environment/AtmosphereV2：光影、流雾和萤火的 3 个母材质与 6 个独立实例。
- BP_RogueCharacter 的 SpringArm → 目标臂长：初始距离 2100 cm。类默认值的最大镜头距离为 3600 cm，最小仍为 700 cm；滚轮可拉近。

林间投影由主光的 Light Function 生成，缓慢漂动。MI_Canopy_Day / Night 中 ShadowFloor 越低，投影越深；PatternScale 越大，图案越细。

MI_GroundMist_Day / Night 的 Tint / Opacity 控制贴地雾的颜色与浓度。雾边缘与内部噪声都渐隐，并使用 Depth Fade；关闭了这类半透明材质自身的顶点雾，避免叠出发亮的矩形。

微光已从较外侧的树后移到空地内缘。MI_Firefly_Day / Night 的 Tint / Energy 控制颜色和能量。夜间采用稀疏、异步明灭的暖金微光，与实心弹幕区分。

夜间原有 SpotLight_0 的强度由 850 调到 0，避免这盏约 2505 cm 范围的补光冲淡局部明暗；石灯笼等点光源保留暖光，位置不变。

## 镜头与抗锯齿

默认镜头由 900 cm 拉远到 2100 cm，让场景边缘、地面光影和更多弹幕进入画面。它保存在玩家蓝图，运行时没有新增强制缩放逻辑；可以继续在蓝图调整。

抗锯齿使用 FXAA（r.AntiAliasingMethod=1）。实机对比中，快速弹幕周围的历史拖痕明显减轻。FXAA 不使用历史帧，远处细草和细边可能比时间抗锯齿更容易闪烁；可在项目渲染设置中选择其他方式重新比较。

## 渲染与性能

- 体积雾开关沿用引擎的阴影质量分档：低/中档关闭，高/极高档开启。去掉了旧的项目强制关闭值，也没有强制覆盖低画质。
- 体积网格采用 GridPixelSize=16、GridSizeZ=64，视距 9500 cm。
- 贴地材质雾和微光没有碰撞、导航影响或 Actor Tick，漂动由材质时间驱动。它们仍然增加透明绘制成本。
- 没有开启 Lumen、光线追踪、实时天光捕捉。本轮没有做高波次 GPU 压测。

## 验证与维护

实际图形渲染检查了昼夜场景、玩家/HUD 和弹幕；重新加载确认镜头距离 2100、FXAA=1、正常阴影质量下体积雾开启。材质编译未报错。低阴影档关闭体积雾的分档检查也通过，并已还原测试改动的本地阴影设置。

保存前比较原有非灯光 Actor 的变换、模型、材质和碰撞，森林、商店、PlayerStart 与刷怪轮廓保留。武器、成长与音频数据没有改动。本轮是资产与配置更新，没有重新编译 C++。

Tools/Presentation/refresh_forest_atmosphere.py 用于重新应用本版环境默认参数，会覆盖这组环境参数和材质图；只在确实要恢复默认风格时运行。正常微调优先改关卡和 MI。

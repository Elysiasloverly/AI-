# 武器与升级卡图标收藏栏

更新：2026-11-04。

战斗右下角显示当前玩家本局持有的武器和选到的升级卡。最早获得的项目在右侧，后获得的新项目依次向左排列；满行后向上换行。重复卡片更新数字，原图标的位置保持不变。

## 显示规则

| 项目 | 显示方式 | 角标含义 |
|---|---|---|
| 初始携带或本局获得的武器 | 每种武器一个图标 | 合并 DT 基础数量与本局数量加成后的实际有效数量，受原有 MaxCount 约束 |
| 七种可叠加武器的数量卡 | 合并至对应武器 | 不另外占一个卡片图标 |
| 通用属性卡、专属效果卡 | 每种升级类型一个图标 | 本局成功选择或购买的次数 |
| 永久升级树的解锁或属性等级 | 不作为本局选卡显示 | 永久效果仍按原系统应用 |

未持有的武器不显示；编辑器启用按武器表初始数量调试时，收藏栏照实显示该数量。本轮没有更改武器初始数量、战斗配置或永久存档。

角色濒死时收藏栏降低透明度，复活后恢复；结算时隐藏。图标不拦截鼠标输入。

## 可编辑入口

- `/Game/UMG/HUD/WBP_OwnedItems`：整体排列。类默认值可调整图标尺寸、间距、每行最多列数、右边距、底边距和左侧状态栏留白。
- `/Game/UMG/HUD/WBP_OwnedItem`：单个图标的底框、图形与数量角标。保留 `ItemIcon`、`StackText` 的名称即可继续使用原生更新。
- `/Game/GameAssets/ArtDirection/Completion/DA_ArtPresentation`：`CardIcons` 对应 33 种升级，`WeaponIcons` 对应八种武器。选卡、商店、升级树与收藏栏共用此配置。
- `/Game/GameAssets/ArtDirection/OwnedItems`：两张透明升级图集、采样主材质以及 28 个独立卡片材质实例。七种武器继续使用 Completion 中的本体图标。
- `ArtSource/OwnedItems`：生成源图与提示词记录。

默认逻辑尺寸 52、间距 7、每行最多 12 列、右与底边距 24、左侧留白 350。实际屏幕尺寸受项目 DPI 缩放影响；较窄窗口会自动减少列数。击杀提示按收藏栏占用高度上移。

图标材质的 `Column`、`Row` 为从 0 开始的 4×4 格子坐标，`Atlas` 为图集贴图；Alpha 从贴图的 A 通道读取。换成独立图标时，直接替换配置中的 UI 材质即可。

## 攻击动效

事件武器沿现有服务器确认的开火表现批次触发所属玩家的图标跳动，没有增加逐发 RPC。连发每一轮各触发一次，齐射的多颗弹体合并为一轮。持续环绕银刃在出现及每转完一圈时触发。

只有对应武器图形跳动，底框、角标和排列位置保持稳定。连续攻击会给正在运动的弹簧追加有限冲量，不会每次强制归零；停止后平滑回落。次数增加时角标轻微放大后归位，新图标淡入。

`WBP_OwnedItem` 可调跳动高度。希望自己用 WBP 动画制作时，开启“蓝图接管动效”，实现 `OnAttackPulse` 和 `OnItemUpdated`；这会停止原生位移、缩放与淡入写入。

## 数据和联机路径

`ARogueCharacter::ApplyUpgrade` → `ARoguePlayerState::RegisterUpgradePick` 记录成功选卡。原计数 Map 继续服务卡池限制；新增有序 `UpgradePickViews` 数组保存首次获得顺序和次数，以 `COND_OwnerOnly` 复制。客户端通过 RepNotify 重建自己的查询计数。

收藏栏每 0.1 秒从本地受控角色的实际武器与所属 PlayerState 构建视图，复用已有图标控件，仅创建新增项目。动效停止后不继续写 Slate 属性。它不查询敌人、不参与伤害计算，也不依赖音量或音效资产。

昼夜无缝切图在 `CopyProperties` 中同时复制计数和有序镜像；新开局清空镜像。永久存档没有新增这些局内记录。

## 本轮验证

- 20 项定向自动化检查通过，覆盖真实选卡合并、重复次数与顺序、OwnerOnly 声明与镜像回调、切图拷贝、图标覆盖、跳动归位，以及原升级树布局和关卡续接。
- 两个独立游戏进程以不同临时存档连接：房主与加入者获得不同卡片，分别核对自己的 HUD 和次数，并确认另一名玩家的选卡镜像未泄露到客户端。
- 临时 PIE 窗口验证 28 项换行、重复次数与图标动画。界面观察通过真实 ApplyUpgrade 施加卡片；隔离刷怪、使用临时检查目标，不保存地图或战斗数据。

这些是本次改动的定向验证，没有重跑整个项目全部测试。

## 冰刀美术接线

冰刀只获取一把，不提供数量卡；四种专属卡分别占据自己的收藏栏项目。获取卡和武器本体使用不同图标，避免两种展示语境共用同一张图。新增 5 张卡及冰刀本体的六个图标实例位于 `/Game/GameAssets/Weapons/FrostBlade/Refined/Materials`。

图标跳动在真正开始横斩时触发；靠近目标过程中目标失效，不会误播出刀音或跳动。旧图集仍保留原先 28 张卡，新图标由 `DA_ArtPresentation` 的映射接入。图标覆盖测试按实际反射枚举计算，不再写死 28。

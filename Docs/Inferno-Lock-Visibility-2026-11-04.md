# 火焰柱锁定圈的正常镜头可见性修正

2026-11-04。用户报告看不到锁定圈。本轮暂停冰刀制作，没有新增武器、模型或升级卡。

最近一次用户编辑器日志确认是Development，时间18:58启动，排除DebugGame旧模块这一猜测。使用其当前樱庭白天/黑夜地图、原角色相机、真实玩家及正常GAS自动开火复测，两个目标都产生了圆环Actor；圆环没有隐藏，材质和火焰柱蓝图引用有效，圆心也在碰撞地面上方。之前的近景摆放预览不能证明默认游戏镜头下能看清。

复测发现视觉不足：旧终点半径45cm且只参考偏小的碰撞胶囊，缩完后主要挤在模型脚底；线宽在远镜头下不足数个像素，淡金色又接近白天地砖颜色。修正如下：

- 自动适配同时参考可见主体的短边和胶囊体，忽略已标记的配饰/伤害区域，避免长扫帚决定圈的尺寸。完成收缩后至少保留“主体参考半径＋模型外沿留白”，外圈至少为该终点的1.8倍。
- 新增 `BP_HellTowerLockRing → 锁定圈 → 模型外沿留白`，默认16cm。关闭“随目标体型扩大”时仍按手填的初始/最终半径显示。
- 材质按屏幕导数维持最小可见线宽，添加深色细边；仍然只有圆环和四个刻度，没有新增粒子或灯光。
- 蓝图离脚底高度8→20cm，透明度0.85→0.95。深度检测保留，避免把正常场景遮挡一律穿透。

默认3秒收缩不变。伤害、锁定范围、GAS节奏、地图和怪物模型保持原值。适配开启时90/45cm是配置基础值，不再承诺所有体型都刚好以90cm开始、45cm结束。

Development Editor已编译并更新。11项定向检查通过，新增“大体型收缩终点仍在身体外、回池后小体型不会继承大尺寸”的回归；原多目标、解除、共享锁定、过期、代数和专属卡/GAS检查通过。白天和黑夜各以两个真实敌人、正常GAS自动攻击持续观察约7秒，默认相机截图已检查；没有手动调用WeaponTick或ActivateRing替代接入。此为受控场景验证，不是完整百波对局；两场并行只作视觉检查，不作性能对比。前次双进程同步检查通过，本轮未改变同步载荷，没有重复跑网络检查。DebugGame未更新。

# 地图场景、刷怪区域与商店摆放

## 当前入口

默认地图：`/Game/GameAssets/StarterContent/Maps/Minimal_Default`。

场景以地图中的物体、灯光和 PlayerStart 为准。GameMode 不再要求 BP_RogueArena，不自动创建商店，不把玩家传送到原点，也不调用自动场景优化覆盖灯光、雾和后处理。

旧竞技场在当前地图中的 9 个静态网格体和 8 盏点光源已转为独立物体，放在「关卡场景」文件夹。旧蓝图资产和原生类保留用于兼容，不再参与当前场景和刷怪范围计算。

## 在地图里框选刷怪范围

1. 当前地图已有「怪物刷新区域」，位于大纲「玩法」文件夹。新地图可在「放置 Actor → 所有类」搜索 `RogueEnemySpawnRegion`（显示名「怪物刷新区域」）拖入。
2. 移动、旋转、缩放该 Actor，或选中 `SpawnBounds` 组件修改「Box Extent」。绿色框就是范围，数值是半尺寸。
3. 框的 Z 范围也参与限制，要包住目标地面和完整敌人胶囊；太扁或没有地面会刷不出怪。
4. 「边缘留白」是怪物胶囊距侧边的最小距离，默认 100 cm。无需碰撞，框本身不会阻挡玩家或怪物。
5. 每张地图放一个刷怪区域。缺少或重复时记录警告并停止自动刷怪；不会悄悄使用世界原点附近的默认范围。

普通怪和 Boss 共用此范围。优先围绕存活玩家取候选点，失败后在整个框内取样；随后向下检测地面并验证完整胶囊空间。框只限制出生地点，不是怪物生成后的移动围栏，也不保证导航可达。

## 不规则中央空地轮廓

当前地图已在同一个刷怪区域上启用「使用不规则刷怪轮廓」，`SpawnOutline` 是沿中央空地布置的 38 点闭合折线，避开树林并留出安全距离。

1. 选中「怪物刷新区域」，在组件中选择 `SpawnOutline`，在视口选中控制点并移动，沿空地边缘调整轮廓。可用编辑器样条控制点菜单增加或删除点。
2. 轮廓支持凹多边形。至少保留三个点，不能自相交、重叠或退化成一条直线。构造时会保持闭合、直线连接，不会重置你编辑的控制点。
3. 轮廓控制世界 XY 范围；点的 Z 不决定地面。原来的 SpawnBounds 仍控制外层空间，必须包住整个轮廓、地面和完整胶囊。
4. 胶囊半径和默认 100 cm 的「边缘留白」也参与检查，因此怪物中心不会紧贴树林边界。Boss 会使用自己的实际胶囊尺寸。
5. 无效轮廓会停止该范围的刷新，不会回退到矩形在树林中出生。关闭「使用不规则刷怪轮廓」才恢复原矩形方式。

当前合并场景网格包含地面与树冠，另已启用「限制地面高度」：区域局部 Z 下限 -520、上限 -490，对应当前变换下的世界 Z 80–110；实测地面约为 93。移动场景或区域后要重新核对这些高度。详见 [地面检测](Enemy-Ground-Spawning.md)。

轮廓限制出生位置；生成后的移动仍由角色与 AI 处理，它不充当导航边界或物理围栏。

## 摆放并编辑商店

蓝图路径：`/Game/BP/BP_RogueShopTerminal`。拖入地图，移动和旋转到需要的位置即可；运行时不会另生成一个商店。

| 组件 | 编辑用途 |
|---|---|
| BaseMesh | 主体静态网格体、材质槽、相对位置与缩放 |
| GlowMesh | 可选装饰网格体、材质槽、相对位置与缩放；不需要时清空网格体 |
| InteractionBox | 玩家靠近后的交互范围；修改形状半尺寸和位置以适配你的模型 |
| PromptAnchor | 交互文字显示位置，随整个商店变换 |

C++ 只创建组件和处理重叠，不再指定商店网格体、材质及模型缩放。初始外观已配置在蓝图组件里，可直接替换。地图实例单独覆盖组件值时，该实例的覆盖值优先于蓝图默认值。

主体和装饰默认无碰撞，交互框对 Pawn 只做重叠。要让模型阻挡角色，可在蓝图模型组件上自行配置碰撞，交互框保持 Pawn Overlap 和 Generate Overlap Events。

场景终端负责外观与接近检测；商品、价格和购买状态仍属于各玩家 PlayerState，权威购买流程仍在服务端。

## 验证

`Rogue.Gameplay.SpawnRegion` 覆盖平移、旋转、非等比缩放、框外玩家、缺少区域、范围过小、框外地面、框外顶棚、胶囊边距及倾斜框的竖直射线裁剪。

`Rogue.Gameplay.MapAuthoring` 覆盖关卡商店不重复生成、模型/材质/缩放与商店变换保留、提示锚点跟随，以及不自动隐藏关卡灯光。地面算法回归见 [Enemy-Ground-Spawning.md](Enemy-Ground-Spawning.md)。

新增 `SpawnRegion` 测试覆盖凹轮廓、边缘胶囊留白、无效轮廓拒绝、平移/旋转/缩放和构造后控制点保留。

# 底部状态栏与角色旁冲刺圆弧

更新于 2026-11-09。资产为 `/Game/UMG/HUD/WBP_PlayerVitals`。

## 当前排版

- 底部居中的暗色圆角面板设计尺寸为 620×144，底部留白 24。等级区、生命/护甲与底部经验各自对齐，圆角与细边框延续原暗色配色。
- 属性名与数值分离：生命值使用较大的字号，靠右对齐；护甲为次一级字号。HealthValueText、ArmorValueText、ExperienceValueText 是可选数值绑定，缺失时兼容旧版完整一行文字。
- 数值放在只缩小不放大的 ScaleBox 内，大数值不会顶出右边界。字体、颜色和缩放区域可在设计器调整。
- 经验改为底部横条，当前经验/下一级经验在左侧，经验增量与升级反馈在右侧独立区域，条底留出间距。
- 无护甲时隐藏数字与护甲条，在原位置显示低对比度“暂无护甲”，获得护甲后自动替换为正常显示。
- 等级区只显示标题与等级数字，已移除重复的 Q/待选计数。`LevelBadge` 内的 `LevelBadgeContent` 垂直容器共同居中 `LevelCaption` / `LevelText`，不再用两份独立 Canvas 坐标对齐。未消费升级统一由状态栏上方的淡蓝色文字提示：“有 N 次升级可选 · 按 Q 打开”，缓慢呼吸闪烁。次数用完或角色濒死时隐藏。
- 冲刺冷却改为角色右侧圆弧：仅在实际充能时出现，从底端向上填充；充满后立即隐藏。深色外沿帮助它在冰面和浅色场景上保持可见。
- 冲刺圆弧显示现有 GAS 冷却比例，不引入新的体力或消耗机制。濒死、不可用及没有实际冷却计时时隐藏，复活后只在仍有冷却时出现。
- 保留原有平滑血条、受击残影、低血提示、经验跨级动画与右下角图标避让。

## 在 WBP 中修改

| 位置 | 可调整内容 |
|---|---|
| WBP_PlayerVitals → LevelBadge → LevelBadgeContent | 等级标题和数字的共同居中、字号与槽位间距 |
| WBP_PlayerVitals → HealthValueScale / ArmorValueScale / ExperienceValueScale | 大数值的只缩小不放大区域 |
| WBP_PlayerVitals → PlayerDashRing 控件 | 半径、圆弧角度、粗细、冷却颜色（默认 HUD 就绪时隐藏） |
| WBP_PlayerVitals → 类默认值 → 角色旁冲刺条 | 屏幕偏移、世界高度偏移 |
| WBP_PlayerVitals → PendingUpgradeHintText | 字体、淡蓝色、描边、状态栏上方的位置 |
| WBP_PlayerVitals → 类默认值 → 升级提示 | 呼吸周期、最低透明度 |

圆弧跟随本地玩家的屏幕投影，每帧处理摄像机变化和 DPI。只有实际剩余时间大于零且进度未满时才投影；没有本地 Pawn、投影在屏幕后方或角色濒死时也不显示。它是界面控件，不参与场景碰撞，也不接受鼠标点击。

UsePlayerSideDashRing 用于将旧冲刺分区迁移到角色旁；RefineCompactVitals 是当前状态栏的精修制作入口。两者都只在编辑器明确执行时写入资产。运行时只更新内容与圆弧投影，不会重建 WBP 或覆盖字体、颜色和圆弧样式。

## 验证

定向测试覆盖真实 GAS 冷却、圆弧比例、充满隐藏、濒死隐藏、复活、升级提示呼吸与用完隐藏；游戏场景预览检查 1440×810 与 1280×720。截图中的状态数值为编辑器预览数据，不写入角色存档。既有验证还覆盖受伤增量分区、百万级生命值、三位等级和无护甲状态；移除等级下方计数后，6 项相关界面测试通过。最新共同居中容器已做资产结构校验，并在正常/三位等级及 1440×810、1280×720 预览检查。

# 星符·流光与焰符·灼光光束外观

星符·流光使用 `/Game/BP/Projectiles/BP_RogueLaserBeam`，焰符·灼光使用 `/Game/BP/Projectiles/BP_RogueHellTowerBeam`。两者继承 `ARogueLaserBeam`，分别保存外观配置。

2026-10-27 更新：星符·流光改为蓝白能量核心与蓝色流光；焰符·灼光改为金色核心、橙色扰动火纹和小型端点光环。光束按本次激活寿命淡入淡出。折射段使用相同的激光表现。

## 在蓝图里修改

两张蓝图均开启“类默认值 → 外观 → 材质 → 使用组件材质”。直接选中组件修改材质槽，编译保存后生效；激活、切换样式和对象池复用不会覆盖这些槽位。旧的样式材质覆盖字段仅用于未开启此选项的兼容类。

| 组件 | 当前激光材质 | 当前焰符·灼光材质 |
|---|---|---|
| BeamMesh | MI_Laser_Core | MI_Flame_Core |
| GlowMesh | MI_Laser_Glow | MI_Flame_Glow |
| StartRingMesh / EndRingMesh | MI_Laser_Endpoint | MI_Flame_Endpoint |

上述材质实例与两张主材质位于 `/Game/GameAssets/Combat/BeamFX/`。原网格和原共享材质资源保留。

修改实例参数：`Tint` 调颜色，`Energy` 调发光亮度，`Opacity` 调叠加层强弱，`FlowSpeed` 调流动速度。激光和焰符·灼光实例独立，调整其中一套不影响另一套。

在对应蓝图“外观 → 星符·流光样式 / 焰符·灼光样式”调整光束粗细、光晕粗细、端点圆环尺寸及开关。当前两套均开启端点圆环。长度始终由射击起终点计算；这些参数不改变伤害或射程。

## 网格轴向与坐标

当前 BeamMesh 使用 X 轴延伸的方块；GlowMesh 使用原有 StarterContent 圆柱，沿本地 Z 轴延伸。蓝图已开启“光晕网格沿 Z 轴延伸”，并将 GlowMesh 旋转到沿光束方向。激活时根据网格包围盒中心补偿底部原点，防止光晕偏移半束长度。

`M_BeamFlow` 的当前坐标约定为：核心 X 范围 −50..50，圆柱 Z 范围 0..100；实例 `Axis=0` 为核心，`Axis=1` 为圆柱。替换为其他尺寸、轴向或原点的网格时，也要调整材质中的坐标归一化。只换材质、颜色或粗细无需修改代码。

## 寿命、对象池与性能

共享材质从组件 Custom Primitive Data 读取：8 为激活世界时间、9 为本次寿命、10 为外观相位。每次复用重写，回收清除寿命并隐藏，不会沿用上次动画；相位不消耗玩法随机流。

流动与淡出在材质中计算，没有增加光束 Actor Tick、运行时动态材质实例或组件。主材质使用无纹理采样的加法发光；透明层仍有像素叠加成本，场上光束很多时应避免过粗或过亮。本次没有进行性能基准测试。

可读着色代码保存在 `SourceArt/VFX/BeamFX/BeamFlow.hlsl` 和 `BeamEndpoint.hlsl`，用于查阅与维护；运行时实际使用已保存的 UE 材质资产，这两个文件不会自动热更新资产。

## 武器配置与联机

`/Game/Data/Weapons/DT_WeaponConfig` 的 HellTower 行引用独立焰符·灼光蓝图，Laser 行引用星符·流光蓝图。服务器仍负责索敌、伤害和攻击频率，客户端使用各自蓝图重放表现。焰符·灼光伤害结算频率、锁定递增、激光折射规则、武器表和音频配置均未因本次外观调整而改变。

回归入口 `Rogue.Gameplay.HellTowerBeam` 覆盖实际蓝图引用、表现重放、组件槽保留、旧材质模式、对象池寿命重置、无效输入和底部原点圆柱居中。另用真实图形渲染验证主材质编译及激光、折射、焰符·灼光画面；NullRHI 测试本身不能验证着色器效果。

# 震荡柱：整圈弹幕

震荡柱保持固定不动，每次向四周均匀发射一圈子弹。旧地面波已从代码和原型表中移除，也不附带接触伤害。

在 `/Game/Data/Enemies/DT_EnemyArchetypes` 中找到「敌人类型 = 震荡柱（ShockPillar）」的行，展开「专属参数（只填当前类型）」→「震荡柱」。当前行名为 `ShockPillar`，代码按敌人类型查找。

| 参数 | 默认值 | 含义 |
|---|---:|---|
| 初始冷却最小/最大值 | 1.6 / 3.2 秒 | 每次生成后随机等待多久开始攻击 |
| 攻击冷却时间 | 4.8 秒 | 两次齐射的间隔 |
| 每圈子弹数量 | 48 | 整圈均匀分布，默认每 7.5 度一发 |
| 子弹速度 | 720 厘米/秒 | 水平向外飞行速度 |
| 最长飞行时间 | 5 秒 | 未命中时到时回收，默认可飞行约 3600 厘米 |
| 子弹大小倍率 | 0.4 | 同时缩放外观和碰撞，密集弹幕保留可穿过的间隙 |
| 单发伤害倍率 | 0.35 | 每发伤害 = 生成时 Profile 中的伤害 × 此倍率 |
| 发射高度 | 48 厘米 | 以柱底为基准，跳跃是否能躲过取决于实际高度和碰撞 |

子弹从柱体周围生成，穿过其他敌人和濒死玩家，命中存活玩家或墙体时回收。密集弹幕使用简化外观，关闭每发动态光源与多余装饰，减少同屏开销。

服务器通过现有远程 GAS 能力发射真实弹体并结算伤害。整圈使用一条可靠多播消息，相关客户端在本地对象池生成零伤害表现弹体；中途加入者不会补画已经发射的子弹。旧地面波结构与能力已删除，震荡柱的参数和运行逻辑只使用 `Ranged / RadialRing`。

# 游戏音效第三版（2026-10-27）

本轮精修24个短音效。全部为原创程序合成，48kHz、单声道、16位PCM，无外部采样。素材路径保持不变，已重导入；背景音乐、武器音量、播放间隔、距离衰减、并发配置及玩家本机音量均保留。

银刃按要求保持静音，三个 `SFX_SilverBlade_Swish_01–03` SoundWave及原始WAV已从项目删除。项目外保留旧版备份，生成器也不再生成银刃声音。`DA_AudioConfig` 中银刃条目仍保留，声音槽为空。

## 备用反馈素材

冲刺、经验拾取、金币、护盾破裂、升级、复活六个素材也已精修，位于 `/Game/Audio/SFX/Feedback`。它们仍是备用素材，没有在本轮新增玩法事件绑定，不会自动在这些事件播放。按钮的UIHover/UIConfirm已接入，不属于未绑定素材。

## 响度与密集攻击

第三版按声音前段的有效RMS进行变体匹配，不再把所有音效归一到同一个峰值。瞬态经柔化、各类声音使用不同的频段和尾音长度，并保留音量余量。五种武器各自三个变体的前段RMS差异最大约0.26dB。这里的RMS是离线测量，不是LUFS或听觉响度保证。

使用当前保存的音量倍率，模拟四名玩家、十二只敌人、八秒内452次攻击的叠加，包含16个武器声/12个怪物声的并发上限。模拟不含距离衰减、背景音乐和真实玩法输入；第三版样本峰值约-2.15dBFS，无削波。该结果用于检查密集声的余量，不代表所有战斗场景一定无削波。

## 源文件和试听

- `Tools/Audio/generate_procedural_sfx.py`：第三版生成器，需要Python及NumPy。
- `SourceArt/Audio/Procedural`：24个源WAV和manifest.json。
- `Weapons-Preview.wav`：冰符·寒弹、星符·流光、焰符·灼光、冰焰·陨星、冰符·霜玉各两个变体，最后为怪物声。
- `Buttons-Preview.wav`：三次悬停，三次按下。
- `Feedback-Preview.wav`：六个备用反馈素材。

```text
python Tools/Audio/generate_procedural_sfx.py --output SourceArt/Audio/Procedural
```

再生成WAV后需要在UE中重导入对应SoundWave。音效资产为非循环、强制内联的短素材；按钮播放走SC_UI，攻击播放走SC_SFX，两者均受“音效音量”控制。背景音乐仍走独立音量。

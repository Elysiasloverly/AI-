# 武器施法与爆炸精修

> 2026-11-06 更新：本文记录旧火丸的暖色效果。当前武器已改为「冰焰·陨星」，采用天降斜坠、冷白核心、冰蓝焰尾和独立的 `BP_CastIceMeteor` / `BP_BlastIceMeteor`。当前配置以 [武器配置指南](Weapon-Configuration.md#冰焰陨星原火丸) 为准。

2026-11-04 后续：当前笔触材质、运动节奏、爆炸优先级及 Boss 镜头回弹见 [战斗特效与冲击节奏精修](Combat-Feel-2026-11-04.md)。下文保留本轮之前的实现与验证记录。

2026-11-04。七种玩家武器使用独立施法闪光，火丸与冰球使用独立爆炸材质。目标是让攻击有起势、扩散与收尾，同时保持弹幕和敌人预警清楚。

## 当前表现与蓝图入口

| 弹体蓝图 | 施法风格 | 施法特效蓝图 | 时长 / 最短间隔 |
|---|---|---|---|
| `BP_RogueProjectile` | 六角冰晶与碎晶 | `BP_CastFrost` | 0.20 / 0.13 秒 |
| `BP_RogueRocketProjectile` | 暖色火花与小焰心 | `BP_CastEmber` | 0.22 / 0.15 秒 |
| `BP_RogueMortarProjectile` | 薄霜环与冰晶 | `BP_CastGlacier` | 0.25 / 0.16 秒 |
| `BP_RogueLaserBeam` | 紫色四芒星 | `BP_CastStar` | 0.19 / 0.17 秒 |
| `BP_RogueHellTowerBeam` | 暖色旋焰 | `BP_CastFlame` | 0.23 / 0.18 秒 |
| `BP_RogueOrbitingBlade` | 细银弧光 | `BP_CastSilver` | 0.20 / 0.20 秒 |
| `BP_RogueReturningTalisman` | 符框与散墨 | `BP_CastOfuda` | 0.24 / 0.14 秒 |

弹体蓝图在 `/Game/BP/Projectiles`。类默认值的“开火特效”控制特效蓝图、颜色、大小倍率、时长、碎光数量与最短触发间隔。间隔只限制视觉密度，实际攻击次数仍按武器数据结算。

九个表现蓝图放在 `/Game/BP/Effects/WeaponCast`。其中 `BP_BlastEmber` 和 `BP_BlastGlacier` 分别接入火丸、冰球的“爆炸中心特效”：

- 火丸：较暖的花瓣状焰心、分段扩散环和少量火星，中心先淡出，外环随后消散，时长 0.42 秒。
- 冰球：较冷的六瓣霜纹、低透明度霜雾、细环与冰屑，时长 0.50 秒。

两者的大小倍率为 1.9，碎光数量为 4。实际爆炸半径继续通过既有逻辑影响有限的视觉缩放；光环本身不是伤害边界。

## 材质怎么改

位置：`/Game/GameAssets/ArtDirection/CastBlast/Materials`。

| 资产 | 用途 |
|---|---|
| `M_WeaponCastPaint` | 七种施法形状的母材质 |
| `MI_CastFrost/Ember/Glacier/Star/Flame/Silver/Ofuda` | 各武器施法实例 |
| `M_ExplosionPaint` | 火焰与冰霜爆炸母材质 |
| `MI_BlastEmber/Glacier` | 两种爆炸实例 |

材质为无光照、双面、半透明，保留深度遮挡，不添加动态灯。`Energy` 调亮度，当前施法为 1.55、爆炸为 1.65；`Style` 选择形状。`Shape`、`Tint`、`Opacity`、`Progress` 由已有表现 Actor 驱动，不要用固定实例值替代动画。

所有形状由材质节点与 UV 计算生成，没有新增贴图依赖。中心、环、碎光共用三个动态材质实例；现有 Tick 同步归一化进度。复用 Actor 时进度归零，动态材质继续复用。

## 密度与数据约束

沿用现有本地对象池：正常负载最多 48 个活动效果，高负载最多 16 个，常驻池上限 64，镜头 5000 cm 外裁剪。没有增加每次攻击的网络 RPC、伤害查询、音效、计时器或表现 Actor 层级。

七个弹体的静态网格、组件变换、基础材质槽与覆盖材质逐项核对一致；`Content/Data` 下 10 个数据资产的文件哈希一致。伤害、攻速、范围、武器数量及敌方弹幕没有在本轮修改。

编辑器模块新增 `PlayPreviewAccent`，只在游戏世界内调用既有对象池，供表现预览使用；不进入运行时模块，也不产生伤害或声音。

## 验证与范围

- Development、DebugGame 编译通过。
- 11 项定向检查通过：施法与音效独立、服务器不重复播放、生命周期与碰撞、混合类型池复用、9 个新表现的材质进度推进与复用归零、GAS 伤害与外观标记、快照去重，以及玩家弹体原缩放规则。
- 真实渲染预览：七种施法、两种爆炸分别拍摄起始、中段、尾段与结束；结束时活动效果均为 0。预览检查没有材质编译失败或默认材质回退。
- 樱庭神社白天、雾湖冰洲白天、红魔钟庭黑夜各拍摄两张正常战斗截图，保留默认镜头与正常战斗。覆盖的是开局短时表现，不代表完整 100 波或本轮重新进行了双进程联机测试。

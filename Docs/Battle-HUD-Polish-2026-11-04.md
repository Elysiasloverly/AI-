# 战斗 HUD 视觉精修与编辑入口

更新于 2026-11-04。这一轮精修四份常驻或短暂出现的战斗 WBP，延续书卷感标题、朱红小标和半透明灰青纸色衬底，让玩家在弹幕中更容易读数。

## 暗色配色恢复（当前）

按最新要求，仅将四个战斗 HUD 配色恢复为暗色：深靛底衬配浅色文字，生命、护盾、经验和冲刺使用原有明亮色相。布局、字体、文字内容、动效，以及三种软底衬的透明度、羽化和样式参数保持原值。没有更改材质引用或重新生成控件。

三份 `MI_BattleHUDSoft*` 的当前线性颜色为 `TopTint=(0.032,0.052,0.079)`、`BottomTint=(0.014,0.024,0.048)`，短笔触使用 `AccentTint=(0.82,0.20,0.26)`。以下浅色数值为历史方案。

本次只改配色资产，不需要编译；已检查保存后的昼夜样例和 720p。四份 WBP 的布局、字体、文字及图表摘要一致，底衬透明度与羽化参数一致，源码、配置、地图及游戏数据共 436 份文件哈希保持一致。

## 柔和底衬（上一版配色）

根据后续反馈，当前四个战斗 WBP 使用半透明灰青纸色衬底，边缘有约 10–11 屏幕像素的羽化，不再使用整块实心浅色卡片。纸色比第一版柔化方案压深一档；文字、原排版与变化动效保留。

玩家状态采用完整但柔和的底衬；Boss 血条与地图题签采用较轻的横向底衬；波数和退治使用更短的局部底衬。长朱红顶线收为很淡的短笔触。纸纹极轻、静止，不使用滚动噪声或额外背景模糊。

当前入口都在 `/Game/GameAssets/ArtDirection/BattleHUD/Materials`：

| 材质实例 | 用途 |
|---|---|
| `MI_BattleHUDSoftVitals` | 玩家状态底衬 |
| `MI_BattleHUDSoftRibbon` | Boss 血条与地图题签 |
| `MI_BattleHUDSoftNotice` | 波数与退治提示 |

母材质为 `M_BattleHUDFrameSoft`。可调 `TopTint`、`BottomTint`、`AccentTint`、`EdgeFeatherPixels`、`PanelOpacity`；`SurfaceStyle` 决定三种底衬形式。当前上部纸色为线性颜色 `(0.46, 0.50, 0.49)`，下部为 `(0.37, 0.43, 0.43)`；三份实例的名义不透明度分别为 0.84、0.85、0.82，还会与边缘及密度遮罩相乘。

着色代码保存在 `ArtSource/BattleHUD/FrameSoft.hlsl`。上一版浅色材质和深色材质保留作为历史方案。当前样式以 WBP 和上述三份实例为准，不要重跑旧版批量样式生成工具。

这次只调整 WBP 和材质，没有 C++ 变更，不需要重新编译模块。已检查昼夜临时样例与 720p 画面；四份 WBP 的排版及原图表节点摘要一致，游戏数据与地图哈希未变。本次没有重跑自动化、整局或联机测试。

## 浅色配色调整（上一版）

根据后续反馈，当前四个战斗 WBP 的底板已从深靛改为浅雾蓝灰，搭配墨蓝标题、深青护盾文字、赭色经验与金币、深绿回血数字。状态条继续使用玫红、青蓝和金色。排版、圆角和原有动效保留。

当前底板使用 `MI_BattleHUDFrameLight`，母材质 `M_BattleHUDFrameLight`，都位于 `/Game/GameAssets/ArtDirection/BattleHUD/Materials`。可在材质实例中独立调整 `TopTint`、`BottomTint`、`EdgeTint`、`AccentTint`、`PanelOpacity`。旧深色 `M_BattleHUDFrame` 保留供回退，以下涉及深色底板的内容属于上一版。

`WBP_PlayerVitals` 类默认值新增 **Rogue → 界面配色**：冲刺就绪文字颜色、冲刺状态文字颜色、回血数字颜色。文字与进度条颜色分别配置，运行时会读取这些设置。其他常驻文字继续直接在设计器调整。

本次 Development / DebugGame 编译通过，8 项血条、生命状态和冲刺定向检查无失败（其中 2 项包含测试临时世界警告）。补充检查了昼夜样例、720p、受击与回血文字。没有重跑完整百波或多人对局。

## 当前样式

| 界面 | 本轮变化 |
|---|---|
| `WBP_PlayerVitals` | 生命、护盾、经验和冲刺配有独立小标；状态条为柔和渐变与圆润端头；取消常亮白圈；经验变化提示与当前经验分开 |
| `WBP_BossHealthBar` | 大标题靠左、真实血量靠右，进度条居下；逻辑尺寸 760×98，位置保持屏幕上方中央 |
| `WBP_KillFeedback` | 书卷感“退治”、朱红小标、较轻的连锁行，底板随原动效一起消退 |
| `WBP_BattlePresentation` | 地图与 Boss 登场提示缩为 490×92 的横向题签，降低对战斗中心的遮挡 |

玩家生命条高 20、护盾条高 14、经验条高 7、冲刺条高 8，宽度沿用逻辑尺寸 366。生命和护盾的伤害残影继续独立插值，显示内容仍由原有真实视图数据填入。未解锁护盾时整行收拢；护盾已解锁但耗尽时保留空条和数值。

本轮保留原有生命、治疗、经验跨级、冲刺冷却、濒死与复活反馈，也保留右下角武器和升级图标的叠加与攻击跳动。未修改战斗公式、敌人弹幕、地图或玩家存档配置。

## 自己怎样修改

四个 WBP 都在 `/Game/UMG/HUD`，排版、字号、颜色和画刷直接在设计器编辑。请保留原有绑定名称，例如 `HealthBar`、`HealthDamageBar`、`ArmorRow`、`ExperienceChangeText`、`DashCooldownText`、`SpiritSeal`、`CuePanel`。

新增素材位于 `/Game/GameAssets/ArtDirection/BattleHUD/Materials`：

| 素材 | 用途 |
|---|---|
| `M_BattleHUDFrame` | 带微弱明暗、细边和短朱红笔触的深靛底板；圆角按屏幕像素计算 |
| `M_BattleBarSilk` | 状态条柔和的纵向渐变和细高光；颜色由 WBP 或原冲刺逻辑调节 |
| `M_BattleSigil` | 六种简洁的小标识，材质参数 `Style` 选择形状 |
| `MI_SigilHealth` / `Armor` / `Experience` | 生命、护盾、经验标识 |
| `MI_SigilDash` / `Wave` / `Gold` | 冲刺、波数和金币标识 |

这些是项目内自制的 UI 材质，没有新增位图或外部素材依赖。原始着色代码保存在 `ArtSource/BattleHUD`。材质本身没有时间循环，不新增 Actor、逐帧计时器或网络消息。

底板使用普通 Image 画刷，由材质计算圆角；不要再将它统一改成旧的 RoundedBox 画刷，以免叠上旧描边。受击反馈的 RoundedBox 设置 `Use Brush Transparency`，保证边光也随透明度淡出。若自行替换材质，应检查未受击、受击中、退治提示完全消失后三种状态。

`RogueUIPolishBuilder::PolishBattleHUD` 保留上一轮深色初值；当前配色以保存的 WBP 与 `MI_BattleHUDFrameLight` 为准。该函数仅为编辑器一次性工具，限制操作这四个 WBP；运行游戏不会调用它或恢复设计器样式。手工修改后无需重跑工具。
